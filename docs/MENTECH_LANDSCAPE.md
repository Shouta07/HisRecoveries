# 男性特化ウェルネス（メンテック）の供給状況 — 「少ない」の検証

> 仮説「男性特化のウェルネスサービスは少ない」を、美容だけでなくウェルネス全般（メンタル/性/予防/総合）で検証。
> 結論：**仮説は正しい。** 男性特化は「メンテック」という言葉が生まれたばかりの黎明期で、女性向け（フェムテック）に大きく遅れている。
> `MENS_WELLNESS_SUPPLY_GAP.md`（美容は箱が飽和）と本書（ウェルネス全般は供給不足）を合わせると、HRの立ち位置が立体的に見える。
> 最終更新: 2026-07-09（公開情報ベース。市場数値は集計範囲で振れ幅あり）

## 0. 結論（3行）

1. **仮説は正しい**：男性特化ウェルネスは「メンテック」という**造語が最近生まれたばかり**の黎明期。フェムテック（女性向け）に周回遅れ。
2. **理由は"沈黙"**：男性の**9割が悩みを医師に相談したことがない**。需要が声にならないから、供給が育ちにくい。
3. **HRの含意**：美容の"箱"は飽和だが（前調査）、**ウェルネス全般で男性特化の伴走層はほぼ空白**。しかも供給が薄いのは「市場がない」からでなく「入口がない」から＝HRの入口設計がそのまま供給ギャップの解になる。

## 1. 「メンテック」はまだ黎明期（言葉が新しいこと自体が証拠）

- **メンテック** = Man × Technology の造語。男性特有の悩み（ED・薄毛・不妊・前立腺・メンタル等）を扱う製品/サービスの総称（[femtech-club][m1] / [Forbes JAPAN][m2]）。
- フェムテック（女性向け）は世界的に確立した用語なのに対し、**メンテックは"これって何ですか？"と説明される段階**（[yoi/TENGA][m3] / [MEN'S NON-NO][m4]）。
- 業界の当事者（TENGAヘルスケア等）自身が「メンテックはフェムテックと比べて**まだ発展途上**」と明言（[LaundryBox][m5]）。

→ **言葉が生まれたばかり＝プレイヤーがまだ少ない＝供給が薄い、の直接証拠。**

## 3. なぜ男性特化は少ないのか（構造的理由）

1. **需要が"声にならない"**：男性は悩みを言葉にしない（9割が未相談）。声にならない需要には、供給側が気づきにくく・投資判断も立てにくい。→ 鶏と卵。
2. **恥・スティグマ**：ED・薄毛・不妊・メンタルは「弱さ」と結びつけられ、相談が最も起きにくい。女性の"婦人科文化"のような社会的インフラが男性にはない。
3. **縦割りの単品**：出てきているメンテックも**単品プロダクト**（検査キット・サプリ等）が中心。**悩み全体に伴走する"横断サービス"はほぼ不在**（`COMPETITIVE_LANDSCAPE_CONCIERGE.md`の結論と一致）。
4. **文化的な追い風は"今"来た**：メンズ美容の一般化（前調査）・メンテックの言葉の登場は、ここ数年の同時進行。つまり**供給が薄いのは市場がないからでなく、始まったばかりだから**。

## 4. 二つの調査を重ねると見える、HRの立体的なポジション

```
              男性向けの供給
美容・見た目 →  箱（クリニック/サロン）は飽和へ ／ 横断ナビは空席  （MENS_WELLNESS_SUPPLY_GAP）
ウェルネス全般 → そもそもプレイヤーが少ない（メンテック黎明期）  （本書）
─────────────────────────────────────────────
共通の空席: 「恥に配慮した入口 × 悩み全体への横断伴走」
          = HR が、美容を入口に、ウェルネス全般へ広げられる白地
```

- **見た目（美容）**は男性が最も相談しやすい"表層の入口"。ここは箱が増えて需要が顕在化している。
- **その奥のウェルネス（メンタル・睡眠・性・予防）**は、供給がまだ薄い＝先行者利益が大きい。
- HRは**「見た目」で信頼を作り、そこから供給の薄いウェルネス全般へ広げる**という、二段構えができる稀有な位置にいる（`FUTURE_STRATEGY_HORIZON.md` H3の横展開と接続）。

## 5. HRへの示唆

1. **「男性特化が少ない」は追い風、かつ賞味期限がある**。メンテックの言葉が広まりきる前に、"メンズウェルネスといえばHR"の第一想起を取りに行く（カテゴリ言語の先取り＝GEOでの引用先になる）。
2. **入口は"見た目"のままで正しい**。ウェルネス全般（性・メンタル等）はスティグマが最も高く、いきなりは相談されない。見た目→信頼→奥の悩み、の順で広げる。
3. **単品ではなく"横断伴走"が差別化**。既存メンテックは単品プロダクトばかり。HRの「人＋システムで悩み全体に伴走」は、この領域でほぼ無競合。
4. **フェムテックの成功パターンを"5年遅れで"なぞれる**。女性向けで効いた型（タブーの正常化・メディア→サービス・匿名の入口）は、男性向けにそのまま転用余地がある（`REFERENCE_PRINCIPLES.md`の正常化原則と一致）。
5. **注意**：性・不妊・メンタル・EDは医療領域が濃く、薬機法・医療広告規制が厳しい。HRが踏み込む場合は「見た目」より一段慎重な法務ゲートが必要（`OFFLINE_EXPERIENCE_CATALOG.md`のゾーン判定＋専門家レビュー）。
