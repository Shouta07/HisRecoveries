# 運用メモ（運営者向け）

サイトには出ない、運営する側の手順と文案です。

このファイルの内容は、まだ **設定されていません**。
「LINEに設定済み」とは報告していません。下の文案をコピーして、
LINE Official Account Manager の該当欄へご自身で貼ってください。

---

## 1. 使う道具は4つだけ

| | 役割 |
|---|---|
| Web（tashikame.app） | 何を売っているか、いくらか、誰が答えるか |
| LINE公式アカウント | 購入前の確認、事前のヒアリング、旅行中のテキスト相談 |
| Stripe | 料金のお支払い |
| Google Meet | 出発前のオンライン相談（1回30分） |

独自のチャット、会員機能、自動予約、Meetの自動発行は作っていません。
日程調整はLINEで手で行い、MeetのURLは決まってから個別に送ります。

---

## 2. LINEのあいさつメッセージ（文案）

LINE Official Account Manager →「あいさつメッセージ」に貼ってください。

LINEのあいさつは1通あたり500文字までです。下の文案は約420文字で、
吹き出し1つに収まります。

```
友だち追加ありがとうございます。
旅のタシカメです。

初めての海外一人旅について、出発前はGoogle Meetで、
旅行中はLINEで相談できるサービスです。

まず、お答えできる内容かを確かめさせてください。
この確認は無料です。

次の4つを、このトークに送ってください。

1. 行き先（国と都市）
2. 出発日と帰国日
3. 一人で海外へ行くのは初めてですか？
4. いまいちばん気になっていること

航空券の番号や旅程表は要りません。

内容を見て、お答えできるかと、対象になる期間、
料金をお返しします。原則24時間以内にご返信します。
主に日本時間の夜に対応しています。

※ 緊急時の対応や、現地への駆けつけはできません。
お急ぎのときは、現地の緊急通報、ご加入の保険会社、
大使館・領事館へご連絡ください。
```

### 貼るときの注意

- **文案の数字を書き換えないでください。** 料金・期間・返信の条件は
  `src/lib/service.ts` が持っていて、サイト側はそこから出しています。
  LINE側だけ書き換えると、サイトと食い違います。
- 緊急時の一文は消さないでください。ここを省くと、助けを呼べる先だと
  思って追加する人が出ます。
- 「24時間以内」を「24時間対応」にしないでください。別の意味になります。

## 3. 1件ごとの流れ

```
1  LINEに4つ届く
2  お答えできるかを判断する（行ったことのある国か／相談の中身）
3  できる／できないを返す     ← できないときは、ここで終わり。無料
4  できる場合：対象期間・返信条件・料金を返す
───────────────── ここから有料 ─────────────────
5  Stripeの決済リンクをLINEで送る
6  入金を確認する（Stripeの管理画面）
7  Meetの日時をLINEで決める
8  日時が決まってから、Meetのリンクを送る
9  出発前に30分話す
10 帰国日まで、LINEで相談を受ける
```

**4つが揃わないうちに決済リンクを送らないでください。**
お答えできない相談に先にお金が入ると、返す手間がかかり、
買った人にも悪いことになります。

## 4. 手元で数えること

サイト側で測れるのは2つだけです。

| 測れる | どこで |
|---|---|
| どの入口ページから来たか | `site_landed` |
| LINEのボタンが押されたか | `line_cta_click`（押された場所つき） |

**ボタンが押された数と、LINEが届いた数は違います。**
押して、友だち追加して、何も書かずに閉じる人がいます。
そこが落ちているのかを知りたいので、同じ数字にはしていません。

下の4つは、手元で数えてください。表計算で足ります。

| 記録する項目 | なぜ要るか |
|---|---|
| 4つが届いた件数（日付だけ） | ボタンのクリックと比べて、どれだけ落ちているか |
| お答えできなかった件数と、その理由 | 断っている内容が偏るなら、書き方か対象を直す |
| お支払いまで進んだ件数 | Stripeの管理画面で確認 |
| 1件あたりにかかった時間（Meet＋LINEの合計） | 3,980円で続けられるかの判断 |

**旅行の内容や個人情報を、アクセス解析に送らないでください。**
行き先も日程も相談内容も、解析には入れていません。
手元の記録にも、名前は要りません。

## 5. 公開の前に設定が要るもの

| 環境変数 | 何を入れるか | 入っていないとどうなるか |
|---|---|---|
| `NEXT_PUBLIC_LINE_URL` | LINE公式アカウントの友だち追加URL（https） | CTAが押せない表示のまま |
| `NEXT_PUBLIC_CONTACT_EMAIL` | 問い合わせ用メール（任意） | 英語・中国語の面のメール導線が出ない |
| `NEXT_PUBLIC_X_HANDLE` | Xのアカウント（任意、`@` 付き） | SNSカードにアカウント名が出ない |
| `LEGAL_TEL` | 電話番号 | **特商法の表記が未完成になり、決済が開きません** |

`NEXT_PUBLIC_PAY_URL` は **サイトには出していません。**
決済リンクは、お答えできることを確かめてからLINEで個別に送る運用です。

消すもの：`STRIPE_PASS_PRICE_ID`。
残っていると月額として請求が通り、表記は買い切りのままになります
（ビルドで止まるようにしてあります）。

## 6. Stripe

- 商品：1旅行 3,980円（税込）・JPY・1回払い
- 自動更新なし（Payment Link、サブスクリプションではない）
- **本番で課金テストをしないでください。** テスト環境のキーで通してください
- 決済リンクは公開ページに貼らず、LINEで個別に送ってください
- 秘密鍵（`STRIPE_SECRET_KEY`）をどこにも貼らないでください

海外カードの受付可否、決済画面の言語、Alipay等の対応は、
Stripeのダッシュボードと公式ドキュメントでご確認ください。
こちらでは確認していないので、サイトには書いていません。

## 7. まだ決まっていないこと

決まるまで、お支払いの受付は開きません（`canCharge()` が false）。

### 返金の条件（`src/lib/legal.ts` の `REFUND_OPEN`）

1. 最初のお返事をしたあと、またはオンライン相談を実施したあとに、
   お客様の都合でキャンセルされた場合
2. オンライン相談の日時を決めたあとに、キャンセルまたは変更された場合
3. 旅行そのものが中止・延期になった場合
4. 対象期間中に、お返事をお届けできなかった場合

決めたら `REFUND_SETTLED` に書き足して、`REFUND_OPEN` から消してください。
空にするだけでは通りません（本文に書かれているかを見ています）。

### 運営者のプロフィール（`src/lib/operator.ts` の `OPERATOR_OPEN`）

| 項目 | なぜ要るか |
|---|---|
| 呼び名 | 相談相手を「誰か」として覚えてもらうため。本名でなくて可 |
| 旅のスタイル | 自分と合うかを判断してもらうため |
| このサービスを始めた理由 | 知名度の代わりになるのは、ここだけ |

埋めると `/about` にその節が出ます。埋めるまでは出ません。

### 都市別の相談ページ（`src/lib/cities.ts` の `CITIES`）

いまは空なので、1枚も公開されていません。

1都市ずつ足してください。必要なのは：

- 都市名と国名（国は「行ったことのある15」のどれか）
- **いつ行ったか／どういう旅だったか** ← ここが空だと公開前に止まります
- そのとき自分が迷ったこと（2つ以上）
- 相談できる例（3つ以上）
- やりとりの見本（任意。「利用イメージ」と明記して出ます）

訪問時期が確認できない都市は、足さないでください。

### 実体験の記事（`src/lib/stories.ts` の `STORIES`）

こちらも空です。実際に書いたものだけを足してください。

- 3段落以上・400字以上（検索のためだけの短文は止まります）
- 一人称が入っていること（一般論だけの記事は止まります）
- 写真は `public/img/stories/` に置いた、ご自身で撮ったものだけ

素材サイトの写真を、ご自身の旅の写真として置かないでください。

## 8. 運営者にご確認いただきたいこと

- **旅行業法**：有料で旅行の相談に答える件。手配・代理・媒介はしないので
  登録が要る行為には当たらないと考えて規約に「旅行業務を行わない」と
  書いていますが、これは当社が決める話ではありません。
  観光庁または都道府県にご確認ください。
  競合が同じ書き方をしているから適法、とは判断していません。
- **LINEヤフー株式会社**：プライバシーに書いた社名。合併後の名称で
  書いていますが、ご確認ください。
- **LINE公式アカウントの運用**：管理画面を誰が見られるか、トークが
  どれだけ残るか、やりとりを書き出して保管するか。
  コードからは分からないので、プライバシーに書けていません。
- **外部サイトからの送客**：ココナラ等のマーケットプレイスから
  LINEやStripeへ誘導する場合は、そのサービスの規約をご確認ください。
  外部誘導が禁止されていることがあります。
