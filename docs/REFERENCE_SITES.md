# His Recoveries 参考サイト分析

> 学ぶべき事例を、カテゴリ別に。各社「何が学べるか／HRへの適用／真似しない点」で整理。
> HR＝His Recoveries。中立・匿名・寄り添い・煽らない、を崩す要素は真似しない。
> 最終更新: 2026-07-08

---

## ⭐ 最重要：まず見るべき3つ

1. **hims（米・男性センシティブ健康D2C）** — HRの立ち位置に世界で最も近い手本。
2. **AGA-news（MSD運営・中立オウンドメディア）** — /areas（中立解説→信頼）の国内手本。
3. **Aesop** — 世界観・エディトリアル・引き算の手本（思想で売る）。

---

## 1. 男性のセンシティブ健康 D2C（世界の手本）

言いにくい悩み（薄毛・ED・肌）を"恥"から外し、確信のあるブランドと低摩擦の導線で売る。**HRの情緒設計・脱スティグマの教科書。**

- **hims / hers** — https://www.hims.com/hair-loss
  - 学ぶ：脱スティグマの語り（「薄毛は5,000万人の男性に」等の統計で"あなただけじゃない"を作る）／洗練された自信ある世界観／診療の摩擦をゼロに近づける導線。
  - HRへ：ヒーロー〜記事の"寄り添い"コピー、統計で正常化、CVの低摩擦化。
  - 真似しない：hims は"治療を売る"。HRは中立で売らない → **同じ情緒設計を、物販でなく"伴走・紹介"に使う**。
- **Numan / Manual / Sons（英）** — https://www.numan.com/hair-loss/men
  - 学ぶ：「身体より心理的影響（自尊心・自己像）」を正面に置く言語化。返金保証など安心設計。
  - HRへ：見た目の悩みを"心理"の言葉で扱う（HRのWhy／manifestoと親和）。

## 2. 悩み解説メディア → 信頼（/areas の国内手本）

- **AGA-news（MSD）** — https://ownedmedia-library.com/713-aga-news/ で事例分析
  - 学ぶ：製薬会社が"中立の解説メディア"として、メカニズム・セルフチェック・FAQを発信し信頼を得る構造。**HRの/areasがまさにこれ。**
  - HRへ：中立解説→出典→FAQ の型を継続。医師監修が入れば一段強くなる。
  - 真似しない：多くのクリニック系オウンドメディアは"自院へ誘導"。HRは中立を武器にする（差別化点）。
- **クリニックのランキング/比較メディア（例：AGA比較記事群）**
  - 学ぶ：検索意図（費用・比較・エリア）の網羅とロングテール。
  - 真似しない：ランキング化・送客アフィリは中立を壊す → HRはやらない。

## 3. 男性の第一印象・メイク・スタイリング（直接/隣接の競合）

現行パッケージ（メイク・服・撮影）の"見せ方・料金提示・予約導線"を学ぶ。

- **イケメン製作所（メンズメイク専門サロン）** — https://ikemen.works/mens_make/
  - 学ぶ：初心者向けの安心設計、体験メニューの入口価格、料金の明示。
  - HRへ：第一印象パッケージの体験導線・初心者歓迎の言語化。
- **パーソナルスタイリング（DROBE / leeap 等）**
  - 学ぶ：「似合うをプロが選ぶ」体験の価値訴求、サブスク/継続の設計。
  - HRへ：服選び同行の価値、継続（定着）への布石。
- **マッチングアプリ写真撮影（Photojoy / マッチングフォト）** — https://matching-photo.com/
  - 学ぶ：婚活×写真の高意図ニーズの捉え方、ビフォーアフターの見せ方（同意前提）、明快な料金・流れ。
  - HRへ：オケージョン（婚活）SEOと撮影の価値提示。※HRは効果誇張・捏造をしない一線を守る。

## 4. ハイエンド・会員制・コンシェルジュ（単価と世界観）

高単価（¥150,000〜）と"招待/限定"の世界観の手本。

- **Executive Ashiya（会員制）** — 会員制・招待の見せ方、非公開の価値、価格を出さない設計。
  - HRへ：ハイエンド枠を将来復活させる際の"格"の作り方（枠の希少性・応相談）。
- **メディカル/ライフスタイル・コンシェルジュ系** — 富裕層向けの"全部お任せ"体験の言語化。
  - HRへ：専属チーム貸切・ワンストップの価値訴求。

## 5. 世界観・思想で売る D2C（情緒・manifestoの手本）

- **Aesop** — https://www.aesop.com/
  - 学ぶ：引き算のデザイン、エディトリアルな言葉、"売り込まない"のに欲しくなる世界観。ユーザーが以前に参照。
  - HRへ：/manifesto・ブランドボイス・静かな説得力（煽らない）。
- **Allbirds / Glossier（コミュニティ）**
  - 学ぶ：思想への共感でファン化、UGC/コミュニティの作り方。
  - HRへ：仲間づくり（manifesto Join us）、匿名UGC（お悩み投稿）への応用。

## 6. 匿名×ナーチャリング（言いにくい悩みのCV）

- **AGA/メンタルのLINEナーチャリング** — 参考：https://wakudori.co.jp/market-trend/aga-market/
  - 学ぶ：言いにくい悩みは、LINEで時間をかけて不安を解消→CVが機能する。タグで出し分け。
  - HRへ：`site.line` を活性化し、匿名のまま相談→伴走のナーチャリング導線。
- **メンタル（cotree / Awarefy 等）**
  - 学ぶ：センシティブ領域の"安心の言葉"設計、匿名・守秘の見せ方。
  - HRへ：恥ずかしさの壁を下げるコピー、守秘の明示。

## まとめ：HRが"いいとこ取り"すべき配合

| 何を | どこから |
|---|---|
| 脱スティグマ・自信の情緒設計 | hims / Numan |
| 中立の解説メディア（/areas） | AGA-news(MSD) |
| 世界観・引き算・思想で売る | Aesop |
| 体験・料金・予約の見せ方 | イケメン製作所 / Photojoy / DROBE |
| 高単価・招待の格 | Executive Ashiya |
| 匿名ナーチャリング（LINE） | AGA/メンタルのLINE運用 |

**HRの独自性＝この配合を"中立（売らない）×完全匿名×寄り添い"で束ねること。** どこか1社の完コピではなく、
「himsの情緒 × AGA-newsの中立 × Aesopの世界観」を、物販でなく"伴走"に載せるのがHRの勝ち筋。
