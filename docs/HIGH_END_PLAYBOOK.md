> 位置づけ：ラダーの最上段＝**価格アンカー**＆**LTVの柱**。完全招待制・選考制。
> 軸：**匿名・中立・束ねる・伴走**（Executive Ashiya の「可視・自前・超富裕」とは別軸で戦う）。
> 関連：`docs/CURATION_PLAYBOOK.md`（権威）, `docs/STRATEGY_ADVERTISING.md`（中立）, `docs/OPS_FIRST_IMPRESSION.md`（現場運用）。

## 0. なぜハイエンドを置くのか
- **アンカー効果**：上限を見せると、第一印象（入口）が「手の届く選択」に見える。
- **LTV**：単発でなく年間伴走＝継続収益。
- **ブランド**：「ここまでやる」を示すと信頼と格が上がる。

---

## 1. どう作るか（Build）

### 商品定義
- 期間：6〜12ヶ月。コンプレックス全体 → 自信 → 定着 → つながり、を**一気通貫**で。
- 約束：効果ではなく「**理解し、選び、続け、定着するまで伴走する**」こと（効果保証はしない）。

### 体制
- **専属コンシェルジュ1名**（窓口・伴走・記憶の保持者）。
- **中立パートナー網**（メイク／スタイリスト／撮影／医療連携）。全員 NDA・**固定委託費**（紹介手数料ゼロ＝中立）。
- 専属1人あたり**担当上限**を決める（品質＝命）。

### データ（パーソナライズの根拠）
- 現在地の可視化：セルフ診断・記録、**任意で血液・睡眠**などのデータ。
- Webアプリで記録・可視化・共有（既存資産）。「あなたのデータに基づく設計」が高単価の根拠。

### 希少性
- **月◯名の限定枠**。完全招待制・選考制。

### 価格設計
- 原価（委託＋運営＋システム）＋ 価値（時短・失敗回避・一気通貫・伴走）。
- アンカーは高めに、**選考後に個別提示**。

## 2. どう売るか（Sell）

### ラダーで売る（いきなり高額を売らない）
```
ギフト / 第一印象(1日)  →  満足  →  Recovery 会員（年間伴走）へアップセル
```

### 売り筋
- **希少性**：完全招待制・選考制＝「誰でも入れない」。
- **信頼**：中立（手数料ゼロ）・完全匿名・守秘・医師監修・キュレーションメディア（＝ミシュラン型の権威）。
- **面談で売る**：売り込まない無料相談 → 現在地を一緒に整理 → 必要なら提案。
- **紹介**：卒業生・会員からの**匿名紹介**（還元ループ）。

### 高単価の正当化（効果は売らない）
- 約束するのは「**失敗回避・時短・恥ずかしさの肩代わり・一気通貫・定着の設計**」。
- **NG**：効果断定・ビフォーアフター誇張・医療的な約束。

## 3. どうやり切るか（Deliver / Operate）

```
オンボーディング（守秘確認・現在地診断・ゴール設定 1〜3個）
  → 計画（領域横断ロードマップ：理解→整理→選ぶ→実行→定着→つながり）
  → 実行（中立に専門家手配＋窓口一本化＋決済集約）
  → 伴走（Webアプリで記録・可視化・定期面談 隔週/月、連絡SLA 48h）
  → 定着 → つながり続ける（OB/アンバサダー）
```

### 品質・運用
- 専属の担当上限を守る／受けすぎない。
- パートナーは NDA・固定委託費・物販誘導禁止で監督（中立）。

### リスク・法務
- 医療免責（診断・治療は連携医療機関）。**効果保証はしない**。
- 匿名データ管理（会員ID・保管期限・削除）。
- キャンセル／返金ポリシーを契約で明示。
- 中立（紹介手数料ゼロ）を契約で明文化。

### KPI（効果指標ではなく）
- 完遂率・継続率・紹介率・専属稼働あたり粗利・「自分で再現できた」自己申告。

---

## 4. 失敗しないための原則
1. **枠を絞る**（品質＞拡大）。
2. **中立を売り物に**（自前で抱え込みすぎない）。
3. **匿名・守秘を徹底**（信頼の核）。
4. **効果を約束しない**（設計・伴走を約束する）。

## 一言
> 同じ超高単価で殴り合わない。**「年間伴走（会員）」をアンカーに、匿名で・中立に・束ねて伴走する**を、彼らにない価値にする。
