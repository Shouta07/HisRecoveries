### 値はリポジトリに置かない

このリポジトリは **public**。代表者名も電話番号も、特定商取引法により
サイト上では公開する。ただし、git の履歴に入れるのは別の話になる。

- サイト上の表記：あとで 050 番号に変えれば、その時点で消える
- git の履歴：残る。fork・キャッシュ・コード検索にも残り、
  消すには履歴の書き換え（force push）が要る

なので値は Vercel の環境変数に入れる。`lib/legal.ts` は最初から
環境変数から読むようにしてある（コードの変更は要らない）。

動作は3段階で確認済み。

| 設定 | 特商法の表記 | `canCharge()` |

| なし | 代表者・電話番号が未記入 | false |
| 代表者＋電話番号 | 揃う | false（Stripeの鍵が無い） |

## 5. 決済のフロー

```
ユーザー
  ↓ Stripe Checkout（当社アカウント・単一）
バイタリティデザイン合同会社
  ↓ 注文の記録・利用権の付与
ユーザー
```

- Checkout Session は **サーバー側でのみ** 生成する
- クライアントから受け取るのは相談の鍵と商品IDのみ。**金額は受け取らない**
  （`price_data.unit_amount` はサーバーが `plans.ts` から引く）
- Webhook は HMAC-SHA256 で署名を検証してから処理する
- `Idempotency-Key` により、二重課金を防ぐ
- 同一 session の再送・重複処理でも、利用権は一度しか付与されない
- Stripe Secret Key はサーバーの環境変数のみ。クライアントへ出さない

## 6. サービス提供のフロー

```
1. ユーザーがWeb上で相談内容（と必要なら画像）を入力
2. Stripe Checkout で決済
3. 決済確定後、当社が内容を確認・整理する
4. 当社が業務委託先の女性回答者へ、回答業務を依頼する
5. 回答者が、実際の女性としての受け取り方を当社へ提供する
6. 当社が必要に応じてAIで整理し、当社のサービスとしてユーザーへ納品する
```

通話の場合、4の段階で当社が日時を調整し、当社が用意したブラウザ上の
仕組みで実施する。電話番号の交換は行わない。録音もしない。

## 10. ユーザーと回答者の「出会い」について（事実）

本サービスは、ユーザーと回答者を恋愛目的で引き合わせる機能を持たない。

実装上、存在しないもの：
相互Like、マッチング、フォロー、自由なDM、友達追加、
外部連絡先の交換、プロフィールの相互閲覧。

利用規約で禁止しているもの（第9条）：
回答者への本サービス外での連絡先交換・面会・交際の要求、
回答者の個人を特定する情報の探索、つきまとい・執拗な連絡。

利用規約で当社が行わないと明記しているもの（第3条）：
交際相手の紹介、ユーザーと回答者との面会の仲介、連絡先交換の媒介。

### トップの絵について（自己申告）

トップの「こんな瞬間、ありませんか？」に置いている絵の吹き出しに、
「脈あり…？」という語が2か所ある。

これは **利用者が抱く疑問** を並べたものであって、
当社が相手の気持ちを判定するという意味ではない。

実際に返すものは、読んだ女性が「自分ならどう受け取るか」であり、
相手の気持ちの判定ではないことを利用規約 第12条に明記している。
文章側のコピーでは、この語を使わないようにビルド時に止めている。

> **ただし、相談の主題は恋愛である。**
> Stripe が本サービスを dating / matchmaking 区分に含めるかどうかは、
> Stripe の判断による。こちらで「該当しない」とは述べない。
> 上記は、ユーザーと回答者の間に出会いを生じさせる機能が無いという事実。

## 11. アダルトサービスとの分離（事実）

商品化していないもの：
性的満足を目的とする通話、性的なライブチャット、性的画像、
ヌード、性的ロールプレイ、エスコート、風俗サービス、
回答者との性的接触、有料の性的やりとり。

これらは、カテゴリ・タグ・オプション・上位プラン・
特典・アップセルのいずれとしても提供していない。

利用規約 第9条で明示的に禁止：
回答者への性的サービスの要求、性的な画像の送信、
性的行為を目的とした通話。

運用：
- 通話の録音は行わない
- 相談内容は回答者へ渡す前に当社が確認する
- 回答者からの申告により、提供の中止・以後の利用のお断りを行う（第13条）

なお、恋愛相談として **距離感・親密さ・境界線・同意** を扱うことはある。
これらを扱うこと自体は禁止していない。
「相談」と「性的サービス」を分けている、というのが実態。
