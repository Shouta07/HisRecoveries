## 1. 改善プログラム（パッケージ）— standard / highend を退避

コンバージョンを「第一印象改善パッケージ」1本に集約。`src/lib/packages.ts` から以下2ティアを外しました。

### standard（スタンダード）
- theme: 血液検査・コンプレックス施術 / price: 目安 ¥100,000〜 / duration: 1〜3ヶ月
- steps: 血液検査（現在地の可視化）/ 悩み別のコンプレックス施術（提携クリニック）/ スタイリング・ケアの型 / 記録と伴走
- value: カモにされない / 原因から、根拠で選ぶ / 最適な施術へ、まっすぐ / 失敗のコストを払わない

### highend（ハイエンド）
- theme: フルパッケージ / 年間伴走 / price: 応相談・完全招待制 / duration: 6ヶ月〜
- steps: 総合可視化 / 領域横断のロードマップ / 提携クリニック・専門家を中立に束ねて実行 / Webアプリ＋専属で伴走 / 定着、つながり続ける
- value: 全部を、一人に任せる / あなたを、覚えている / 定着まで、続く / 完全招待制・限定枠

> 完全な定義は上記コミットの `src/lib/packages.ts` を参照。
