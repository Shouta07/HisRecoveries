# His Recoveries 集客戦略 — SEO / GEO / マーケティング

> 男性のコンプレックス（薄毛・汗とにおい・ニキビ/肌・顔の印象・体毛・自意識）を、
> 完全匿名・完全守秘・中立（売らない）で伴走するウェルネスサービス。
> このドキュメントは「いま何が実装されているか」と「どう集客を伸ばすか」を1枚でまとめたもの。

最終更新: 2026-06-30

---

## 0. 結論（先に要点）

- **集客の主エンジンは検索 ×「黙って一人で調べる」瞬間の獲得。** ターゲットは人に言えない悩みを、深夜に・匿名で・最近は ChatGPT / Perplexity に聞く。だから施策の中心は **オウンドメディア（/areas）の網羅** と **GEO（AI検索に引用される設計）** の2本。
- **技術的な土台はほぼ完成している。** robots / sitemap / llms.txt / JSON-LD（Article・FAQ・Breadcrumb・Organization・WebSite）/ canonical / OGP / GA4 / Search Console まで実装済み。**いま足りないのは「中身の量」と「外部からの信頼（被リンク・指名検索）」と「公開（デプロイ）」。**
- **最大の構造的ハンデは2つ:** ①医療系（YMYL）なのに運営が匿名 → Google の E-E-A-T で不利、②新規ドメイン（2026〜）で権威ゼロ。**これを「中立・医師監修・出典明記・組織としての信頼」で埋める**のが勝ち筋。
- **最大の即効ボトルネック: デプロイ。** コードがどれだけ整っても、本番に出ていなければ1ページもインデックスされない。最優先で公開フローを確定する（末尾「実行上の前提」参照）。

## 1. 誰に・どの瞬間に届けるか

### ターゲットの検索心理
男性の外見コンプレックスは「相談しにくい・恥ずかしい・でも気になる」。だから:

- **能動検索が起きやすい。** 自分から「AGA 初期症状」「ワキガ 原因」「ニキビ跡 消えない」と打つ。**指名買い前の、悩み起点の検索が主戦場。**
- **匿名で完結したい。** 顔出し・実名のサービスは心理的ハードルが高い。→ 当サービスの「完全匿名」が差別化として効く。
- **AIに聞く層が急増。** 恥ずかしい質問ほど対人を避けて AI に聞く。→ **GEO（後述）が CV に直結する珍しい業種。**
- **売り込みに警戒している。** 調べると広告・クリニック誘導ばかり → うんざりしている。→ **「売らない・中立」が刺さる。**

### ファネル（獲得の地図）
```
[気づき]        悩みワードで検索 / AIに質問
   ↓            └ /areas の解説記事・AI回答内での引用で出会う
[理解・信頼]    中立で煽らない解説 → 「ここは売り込んでこない」
   ↓            └ pillar/cluster の回遊・出典(MSD)・医師監修
[検討]          改善プログラム（ギフト/スタンダード/ハイエンド）を見る
   ↓
[CV]            完全匿名で予約登録（/apply, BookingCTA）
   ↓
[継続]          Webアプリ伴走 → 紹介・ギフト・指名検索を生む
```

## 3. SEO戦略（検索からの集客）

### 3-1. ピラー&クラスタを「面」で取る（最重要・最大の伸びしろ）
いまは pillar 6 × cluster 9 = **15記事のみ**。検索意図はこの何倍もある。**各領域を「原因→セルフチェック→対処の考え方→受診の目安→費用/期間の相場観→ビフォーアフターの考え方」で網羅**し、領域ごとに10〜15本まで増やす。

優先追加クラスタ（検索ボリューム×意図の強さで選定）:

- **hair**: 「AGA 治療 種類（違い）」「ミノキシジル とは」「つむじ はげ 改善」「m字 ハゲ 基準」「AGA 費用 相場」
- **sweat**: 「ワキガ 手術 デメリット」「多汗症 病院 何科」「制汗剤 効かない」「すそわきが」「汗 緊張 対策」
- **skin**: 「クレーター ニキビ跡 治療」「赤み ニキビ跡」「メンズ スキンケア 順番」「皮脂 多い 原因」
- **face**: 「クマ 種類 改善」「ほうれい線 男」「エラ 張り 原因」「目の下 たるみ 男」
- **body-hair**: 「ヒゲ 脱毛 メリット デメリット」「VIO 脱毛 男 必要」「青ヒゲ 解消」
- **self**: 「容姿 醜形 不安」「人の目 気になる 改善」「自信 つけ方 外見」

各記事の必須ブロック（テンプレ固定）:
1. **要点3行**（要約スニペット & AI抽出用）
2. **本文**（原因→仕組み、煽らず・断定せず・効果に言及せず）
3. **FAQ 3問**（FAQPage schema → Googleリッチリザルト & AI回答素材）
4. **受診/相談の目安**（中立。医療は連携医療機関）
5. **出典**（MSD等の一次情報）
6. **関連記事 + プログラムへの導線**

### 3-2. E-E-A-T の弱点を埋める（健康=YMYL対策）
匿名運営は健康ジャンルで不利。次で「組織としての信頼」を立てる:

- **医師監修を“本当に”実装し、明示する。** 監修者の肩書き（個人特定なしでも「監修医（皮膚科専門医）」等）+ 監修日 + 更新日を各記事に表示。schema の `reviewedBy` / `author=Organization` を活用。
- **一次情報の引用を全記事へ**（現状 face が空 → 補う）。学会・MSD・厚労省など。
- **「中立・売らない」の明示**を信頼シグナルに。利益相反がないことが E-E-A-T の `Trust` に効く。
- **運営者情報の最小開示**（会社名=バイタリティデザイン合同会社、連絡先、ポリシー）。匿名は“利用者の”匿名であって、運営の透明性は別。`/privacy` と Organization schema で担保。

### 3-3. 内部リンク & トピッククラスタの強化
- pillar を各クラスタから必ず上位リンク（pillar の権威を集約）。
- 関連クラスタ同士を文脈リンク（例: 「ワキガ原因」↔「多汗症 量とにおい」）。
- ホーム → /areas を主導線として強調（現状OK）。

### 3-4. 被リンク・サイテーション（ドメイン権威の獲得）
新規ドメインの最大の弱点。広告ではなく信頼で積む:

- **note / Substack / X / Threads** から本体記事へ継続発信（sameAs 済み）。一次は自社メディア、誘導先は /areas。
- **比較・まとめ系メディアやコミュニティでの自然言及**を狙う（中立ポジションは引用されやすい）。
- **PR的アングル:** 「売らない男性ウェルネス」「完全匿名」という編集価値で、メディア露出・寄稿を狙う。
- 法人登記・各SNSの NAP（名称・連絡先）を統一（サイテーション一致）。

## 4. GEO戦略（AI検索・生成エンジン最適化）

この業種は **「対人で聞けない質問を AI に投げる」**ため、GEO の費用対効果が異常に高い。目標は **ChatGPT / Perplexity / Google AI Overviews / Claude の回答内で “His Recoveries” が出典として引用される**こと。

### 既にできていること
- AIクローラ全許可（robots）、llms.txt の引用ガイド、FAQ/Article schema、要点3行。

### さらにやること
- **「質問＝見出し」化。** 記事の H2/FAQ を、実際に人が AI へ打つ自然文に寄せる（「AGAの初期症状は？」「ワキガは自分で気づける？」）。AIは Q&A 構造を引用しやすい。
- **抽出されやすい一文を各記事冒頭に置く。** 定義・結論を1文で言い切る（断定でなく説明として）。要点3行は維持・全記事必須化。
- **出典の明記とリンクを徹底**（llms.txt のガイド通り）。AIは「出典付きで中立」な情報源を好んで引用する。中立ポジションは GEO で最強の武器。
- **更新日を常に新しく保つ**（dateModified）。AIも検索も鮮度を見る。
- **エンティティの一貫性**（Organization schema の knowsAbout / sameAs）で「His Recoveries＝男性コンプレックスの中立解説者」という実体をAIに学習させる。
- **計測:** 「ChatGPT / Perplexity 経由の流入」を GA4 の参照元（chatgpt.com, perplexity.ai 等）で監視し、引用されている記事を強化。

## 5. ソーシャル / オフサイト（流入の二本目）

匿名・中立ゆえに「顔出しインフルエンサー型」は使えない。**編集力と無償の価値提供で信頼を積む型**にする。

- **Threads（主力）:** 既存の「ギフト・マーケティング」プレイブック（`docs/MARKETING_THREADS_GIFT.md`）を運用。悩みに寄り添う短文 + /areas へ。**「大切な人へ贈れる」アングル**で拡散とギフト需要を同時に取る。
- **X:** 検索発見性。記事の要点を引用ポスト、ロングテール語を自然に含める。
- **note / Substack:** 長文の信頼形成。当事者視点（実名・顔は非公開）のエッセイ → 本体記事へ。被リンクにもなる。
- **共通ルール:** 煽らない・断定しない・効果を約束しない・ビフォーアフターで誇張しない。**“静かな信頼”がブランドの一貫性**。

## 6. コンバージョン設計（来た人を逃さない）

- **完全匿名で予約登録**（/apply, BookingCTA）— 心理的ハードルを最小化（最大の差別化を導線でも体現）。
- **記事末の導線を一貫させる:** 「仕組みを知る → 改善プログラム → 匿名で相談」。煽らず、選択肢として提示。
- **3ティアの役割分担で取りこぼさない:** ギフト（始めやすさ/贈れる）→ スタンダード（原因から/カモにされない）→ ハイエンド（全任せ/招待制）。価格は目安、単価非提示で相談誘導。
- **計測済みCVイベント**（hero_cta_click / article_cta_click / gathering_apply 等）で、どの記事が CV を生むかを可視化 → 勝ち記事に追加投資。

## 9. リスク・制約（守るべき前提）

- **YMYL × 匿名**: 効果断定・誇大表現は厳禁（薬機法/景表法）。「効果に言及しない・完了形を避ける・煽らない」を全コンテンツで徹底。医療行為は連携医療機関、当社は伴走。
- **中立の維持**: 特定医療機関の推奨・手数料収受をUIで訴求しない（中立=最大の moat かつ GEO/E-E-A-T の武器）。
- **B2Cのみ**: パートナーサロン/ライセンス等のB2Bは本サイトに載せない。
- **公開依存**: すべての施策はデプロイされて初めて効く。Phase 0 を飛ばさない。
