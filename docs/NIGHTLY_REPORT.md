## 【Stripe / ticket】

購入 → Webhook → 5回付与 → その相談に1回使う。
減らすのも返すのも Postgres の関数。行を押さえたまま数える。

    consume  -1
    refund   +1
    bonus    +1（運営）
    admin    ±（理由を必ず書く）

残り = 買った回数 + 足した回数 + 出入りの合計
