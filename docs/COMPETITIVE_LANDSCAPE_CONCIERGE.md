# 競合・近接プレイヤー調査 — 「医療×サロン×人間コーディネート」の着想

> His Recoveries が向かう方向（男性の悩み起点・医療+サロン+ウェルネスの束ね・匿名・人間+AIの伴走・
> 対価あり）に近い着想の企業を、国内外・隣接業態で調査。結論：**この組み合わせを丸ごとやっている
> 会社は見つからなかった**が、要素ごとに近い実例は複数ある。
> 最終更新: 2026-07-09

---

## 0. 結論（先に）

**「男性の恥・匿名 × 医療+サロン+メンタルの横断 × 人間コーディネーター」を全部満たす会社は、
国内外含めて見つかりませんでした。** 各要素は個別に存在します：

| 要素 | 一番近い実例 |
|---|---|
| 中立な美容医療マッチング（性別不問） | NERO（日本） |
| 医療+渡航+決済代行の一括コーディネート（座組の実例） | 医療ツーリズム各社（日本） |
| 男性特化・対面重視の会員制クリニック | Gameday Men's Health（米国） |
| 検査×人間コーチの伴走型 | Lifeforce（米国） |
| 複数専門家を束ねる高単価コンシェルジュ | Fountain Life（米国） |

HRの独自性は、**これらの要素を「男性の言えない恥」という一点に向けて統合していること**にあります。

## 1. 日本 — 美容医療マッチング/メディア（中立標榜・性別不問）

### NERO（株式会社RADIEN運営）
- 月間7万人読者の美容医療メディア。医師60名超への取材をもとに「中立・透明性」を標榜。
- **「判断軸」を提供するマッチング基盤**と自称——情報過多の中から最適な医療を選ぶ軸を示す設計思想は、HRの「なぜ起こるのか」解説と近い発想。
- ただし**女性中心・美容医療全般**が対象で、男性特化でも匿名性訴求でもない。**人間による同行・伴走もない**（メディア＋マッチングのみ）。
- 出典: [PR TIMES](https://prtimes.jp/main/html/rd/p/000000001.000154596.html) / [nero-drbeauty.com](https://nero-drbeauty.com/)

### Tribeau（トリビュー）
- 日本最大級の美容医療プラットフォーム。レビュー・検索・予約を一元化、「クリニック選定アシスト」を特許出願。
- **セルフサービス型**（人間コーディネーターが同行・翻訳する設計ではない）。HRとは"人が介在するか"で明確に分かれる。
- 出典: [corp.tribeau.jp](https://corp.tribeau.jp/)

## 2. 日本 — 医療ツーリズム・コンシェルジュ（座組の実在証拠）

前回議論した**「立替受領（決済代行）＋コーディネートフィー」という座組**は、実は既に確立した業態でした。

- **JTB／HIS／南海国際旅行／株式会社グランツーリズム／コノミティ**など、旅行業登録企業が「医療機関の調整・予約、健診・治療代金の**代理受領**、医療通訳、査証の身元保証」までワンストップで提供。
- 南海国際旅行は2010年から参入し、**治療代金の立替払い（代理受領）＋通訳＋渡航手配**を束ねている——これは前回設計した「立替払い型座組」が机上の空論ではなく、**既に日本で合法的に運用されている実務**であることの裏付けです。
- 対象は主に**訪日外国人患者**で、国内男性の恥・匿名という文脈はない。美容も含むが「複合的ウェルネス」ではなく医療（人間ドック・美容医療・再生医療・がん治療等）が中心。
- 出典: [南海国際旅行](https://www.nankai-travel.com/medical) / [JTB](https://www.jtbbwt.com/business/service/solution/inbound/japan-travel-note/medical-healthtourism/) / [グランツーリズム](https://grantourism.com/tourism/medical_tourism/)

## 3. 米国 — メンズウェルネス×コンシェルジュ型クリニック

### Gameday Men's Health
- 2018年創業。対面重視・ホルモン最適化/再生医療。2026年時点で**400超クリニック**、48州+カナダに展開、2022年からフランチャイズ化し急拡大。
- 「コンシェルジュ級の利便性（即予約・透明価格）＋対面の臨床」を明言——**Telehealth全盛への逆張り**として対面を売りにする点はHRの"同行"価値と思想が近い。
- ただし**自社クリニックのチェーン**であり、HRのような**独立した中立コーディネーター層**ではない。「恥・匿名」より「パフォーマンス・活力の最適化」というポジティブな訴求軸。
- 出典: [Forbes, 2026-02-20](https://www.forbes.com/sites/tanyaakim/2026/02/20/the-mens-wellness-clinics-scaling-a-new-concierge-like-model/)

### Lifeforce
- オンライン男性ヘルスプラットフォーム。50以上のバイオマーカー検査＋医師の個別面談＋**専属ヘルスコーチ**をセットで提供。
- **「検査データ×人間のコーチが伴走する」構造はHRの人間コーディネート思想に近い**。ただし対象は健康最適化（ホルモン・代謝等）で、外見・恥・第一印象の文脈は薄い。

### Fountain Life（APEXメンバーシップ）
- コンシェルジュ×ロンジェビティ医療。**専属医師・看護師・ヘルスコーチ・栄養士・ケアコーディネーターの統合チーム**が年間を通じて伴走する高単価会員制。
- 「**複数の専門家を一人の顧客のために束ねる**」という構造は、HRの「総仕上げ（ハイエンド）」パッケージの設計思想と最も近い実例。
- ただし**健康寿命起点**（老化・パフォーマンス）で、コンプレックス・恥・匿名という文脈はない。既存の主治医関係と並走する設計（HRのように"窓口を一本化する"より"追加する"位置づけ）。
- 出典: [Fountain Life](https://www.fountainlife.com/blog/medical-concierge-services-for-longevity)

## 4. HRの立ち位置（白地の確認）

```
                  恥・匿名を扱う  |  扱わない
医療のみ          （見つからず）  |  Gameday, Lifeforce
医療+サロン+メンタル束ね  HR      |  Fountain Life
中立マッチングのみ（人が介在しない）| NERO, Tribeau
座組（立替+コーディネート）の実例 |  医療ツーリズム各社（男性特化ではない）
```

- **「恥・匿名」×「医療+サロン+メンタルの横断」×「人間コーディネーター」の3点を同時に満たす例は、調査した範囲では存在しない。**
- 最も近いのは **Fountain Life（統合チーム型の伴走構造）** と **医療ツーリズム各社（座組の実務）** の"合成"。HRはこれを**男性の恥という一点**に向けて再設計している点が独自性。
- リスクとして：Fountain Life・Gamedayのような"パフォーマンス最適化"軸への転換（恥ではなくポジティブな自己投資として訴求）は、市場が大きいアメリカでは実証済みの成功パターン。HRも将来的にこの訴求軸を選択肢として持てる（`REFERENCE_PRINCIPLES.md`の"正常化"原則とも整合）。

## 5. 示唆

1. **座組の不安は解消**：医療ツーリズム業界が「立替受領＋コーディネートフィー」を何十年も合法運用している実例がある。弁護士レビューの土台として引用できる。
2. **NEROは将来の協業/ベンチマーク候補**：中立美容医療メディアとして先行しており、直接の競合にはならない（男性特化でないため）が、医師ネットワークとの連携モデルは参考になる。
3. **Fountain Life型の「統合チーム会員制」は、ハイエンドパッケージ（¥400,000〜800,000）の型として転用可能**。
4. **恥ベースの訴求は、実は米国でも手つかずの領域**。Gameday/Lifeforceは「弱さ」でなく「最適化・パフォーマンス」で売っている——HRが恥・匿名を正面から扱うのは、意図的にニッチだが空いている選択。
