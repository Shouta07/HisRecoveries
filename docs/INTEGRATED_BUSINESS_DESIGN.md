## 2. 提供価値（ステークホルダー別）と社会課題への接続

### 顧客（男性）のペイン → HRの価値
| ペイン | HRの解 |
|---|---|
| どこに行けばいいか分からない | 判断軸（Library）＋人の見立て（E5） |
| 恥ずかしくて相談できない | 完全匿名・実名不要・言えない事情の"翻訳者"（E0） |
| カモにされる不安 | 同行・その場の代弁・逓減コミッションで過剰施術の動機を構造的に排除 |
| 続かない・孤独 | 人＋システムの伴走（LINE定点＋人のエスカレーション） |

### 社会課題への接続（これが事業の正当性）
- **沈黙する500万人**（AGA自覚で未行動）・男性の援助希求の低さ（`MARKET_THESIS.md` §2）は、個人の性格ではなく**構造の欠落**（恥に配慮した入口が無い）。HRはその構造を作る事業。
- 男性の孤独・メンタルヘルス問題の入口として「見た目の悩み」は最も相談しやすい表層。ここから支援に繋ぐ導線は**公衆衛生的にも意味がある**。
- パートナー側の課題（美容医療の広告費高騰・信頼低下・「冬の時代」）にも、質の高い送客と現場DXで応える。**三方の誰かから搾取して成立するモデルではない**ことが、長期の儲けの条件。

### バイタリティデザイン（会社）の儲かる構造 — 二階建てエンジン
```
エンジン1: His Recoveries（B2C＋B2Bコミッション）
  顧客フィー＋提携先コミッション → 粗利率70%水準の収益

エンジン2: VD システム事業（B2B・本業）
  HR提携先（クリニック/サロン）への業務システム・AI導入の受託開発
  → HRのパートナー網が、そのままVDの営業パイプラインになる

フライホイール:
  取材 → 提携 → 送客実績 → 信頼 → システム受託 → 現場データ・関係深化 → さらに提携
```
**HRは単体でも黒字化できる設計にしつつ、VDのシステム受託が乗ると1パートナーあたりのLTVが跳ねる**（送客コミッション＋開発費＋保守月額）。

## 5. 採用戦略（人＋AIの体制設計）

**原則: 「揺れる瞬間」を扱える人だけを採る。それ以外はAIと業務委託で賄う。**

### フェーズ別の体制
| フェーズ | 体制 | 採用の中身 |
|---|---|---|
| Phase 1（〜10件） | founder＋AI＋業務委託3職種 | メイク/スタイリスト/カメラマンを**取材経由で**業務委託化（採用コストほぼゼロ） |
| Phase 2（月5件〜） | ＋コーディネーター1号 | **最重要採用**。下記プロファイル |
| Phase 3（月10件〜） | ＋パートナーセールス兼品質管理 | 覆面調査・提携開拓を分離 |

### コーディネーター1号のプロファイル（この採用が事業の複製可能性を決める）
- **当事者性**: 外見・自意識の悩みを自分ごとで通過した経験（履歴書でなく対話で見る）
- **翻訳力**: 医療用語⇄生活の言葉、顧客の言えない事情⇄現場への要望
- **守秘の体質**: 匿名運営の重さを理解できる人
- **出身プール（優先順）**: ①HRの顧客卒業生（最強。当事者性と体験理解が保証済み）②看護師・医療事務経験者（医療の翻訳力）③美容部員・スタイリスト出身（現場感）
- **AIが下支えする前提で採る**: 記録・リマインド・下書きはAIが担うため、「事務能力」より「人の揺れに気づく力」で選ぶ。採用時の見極めは**同行のロールプレイ**で行う。

### 採用もブランドで行う
`/manifesto`のJoin us・`/partners`が採用の入口を兼ねる（実装済み）。「男性のウェルネスを盛り上げたい」という思想への共感者を、取材→業務委託→社員の順で段階的に深く巻き込む。**いきなり雇わない**（互いの見極めコストを取材と業務委託で吸収する）。

## 6. パートナーセールス戦略（2つのフックを一本のパイプラインに）

現在の接点は2つ: **①男性ウェルネスに共感する現場プロへの取材** ②**VDの現場システム導入**。
これを別々の活動にせず、**同じパイプラインの2つの入口**として設計する。

```
入口A: 取材（共感ベース）           入口B: VDシステム商談（実利ベース）
  │ 露出・被リンクを先に渡す           │ 業務課題の解決を先に渡す
  ▼                                   ▼
        関係構築（信頼・現場理解）
                 │
                 ▼
     提携提案（対価契約・COMMISSION_RATE_DESIGN の率で）
     セールストーク: 「広告費より安い、成果連動の患者獲得」
                 │
                 ▼
     パッケージ組み込み → 送客実績 → 四半期レビュー
                 │
                 ├─→ 実績を基に VD システム受託へ拡張（入口Aから来た先へ）
                 └─→ 満足度データを次の提携営業の実績資料に
```

### セールスの核となる提案価値（クリニック側の損得勘定）
- 美容医療の広告費は高騰し（リスティング・ポータル掲載費）、**成約するか不明なクリックに前払い**している。
- HRのコミッション（8〜25%・逓減）は**成約時のみ発生**。しかも来る顧客は「期待値調整済み・ミスマッチが少ない・ドタキャンしにくい」。
- **「広告費（前払い・水物）を、成果報酬（後払い・確実）に置き換えませんか」**が一言のピッチ。
- 加えて入口Bでは「予約・顧客管理・AI応対のシステム導入」で現場の実務ペインを解決（VDの本業）。**取引の入口が2つあるので、どちらかで断られても関係が切れない**。

### 進め方（数字）
- 最初の90日: 取材10件（既存`INTERVIEW_PROGRAM.md`のペース）＋うち提携提案3件＋成約1〜2件を目標。
- 提携先は**少数精鋭**を維持（`REFERRAL_MODEL_PIVOT.md`: 量産型の患者紹介ビジネスと一線を画すことが法的リスク低減も兼ねる）。
- パートナー1社あたりのLTV = 送客コミッション（年間）＋VDシステム開発・保守。**この合算LTVで開拓コストを判断する**（HR単体で見ない）。

## 7. この設計が「儲かる×ペイン解消」を両立する理由（1段で要約）

```
顧客: 恥の壁を越えられる（社会課題の解消）→ 高い納得度で払う
提携先: 広告より安く良質な顧客が来る＋現場DXが進む → 対価を払う理由がある
HR/VD: フィー（粗利70%）＋コミッション＋システム受託の三重取り
       固定費が軽い（月¥6〜8万）ので月2件で黒字ライン
       人は「揺れる瞬間」だけ、残りはAI → スケールしても品質が崩れない
```

**搾取する相手がいない**（顧客は不安の解消に、提携先は獲得コストの改善に、正当に払う）。
だからこの構造は続く。逆に言えば、**逓減コミッション・掲載は買えない・覆面調査**という
「儲けすぎを自制する装置」を外した瞬間に、ただの患者紹介ビジネスに堕ちて全部が壊れる。
装置ごと守ること。
