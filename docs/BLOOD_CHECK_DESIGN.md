# 血液診断（内側の現在地）— 商品設計

> 目的：第一印象パッケージに加え、**血液診断を商品ラインに組み込む**設計。提携クリニック1社は確保済み。
> 参照競合：Gentsome（gentsome.jp / MenLab株式会社）— 男性更年期特化の検査・受診支援プラットフォーム。
> 戦略仮説（Shouta）：**「将来を予防する」「現在地を知る」へペルソナを少しずらせば当たる。**
> ※ 設計資料。法的・医学的助言ではない。実装前に医事法弁護士レビュー必須（CLINIC_PARTNERSHIP.md の座組に準拠）。
> 最終更新: 2026-07-14

## 0. 結論（3行）

1. **ペルソナをずらす**：Gentsome は「不調が出ている働く男性」（修理・更年期）。HRは**「まだ深刻ではないが、疲れやすさ・見た目の変化が気になり始めた30-40代」**（予防・最適化）。悪いところを探す検査ではなく、**現在地を知る検査**として売る。
2. **HRだけの型＝外側×内側**：印象診断（外側の現在地・90分）と血液診断（内側の現在地）を**鏡合わせ**にし、「現在地セット」で束ねる。見た目の会社が血液をやるから意味が出る——**「疲れて見える」の内側要因まで一本の線**になる。
3. **座組は実証済みの非医療型**：検査・採血・数値の解釈は提携クリニック（自由診療）。HRは予約導線・可視化（レーダー）・生活の選択肢整理・記録（Accord）という**非医療の伴走のみ**。Gentsome Check が同じ構造で公に営業している＝この座組の市場妥当性の傍証。

| | Gentsome | **His Recoveries** |

| 語り | 更年期・障害・受診 | **現在地・整える・育てる** |

**コピーの軸**：
- 「悪いところを探す検査では、ありません。**現在地を知る検査**です。」

## 3. 商品設計 —「外側×内側の現在地」

### 3-1. 商品ラダー（改訂）

```
無料の匿名相談
   ↓
【現在地を知る】← 新レイヤー
   ├ 外側の現在地：印象診断 ¥22,000（90分・要素分解・整える順番）
   ├ 内側の現在地：血液コンディション・チェック（下記）
   └ セット「現在地パッケージ」（外側＋内側・割引）
   ↓
第一印象改善パッケージ ¥150,000〜（1日・取扱説明書）
   ↓
（必要な人だけ）医療への中立な案内 → メンテ・再検査（レーダーが育つ）
```

### 3-2. 血液コンディション・チェック（新商品）

- **中身**：①提携クリニックでの採血（自由診療。検査項目はレーダー6軸に対応：テストステロン/フェリチン/亜鉛/ビタミンD/HbA1c/LDL ほかクリニック推奨項目）→ ②結果を**6ステータスのレーダー＋CONDITION**で可視化（/member 実装済み）→ ③**60分の伴走セッション**（数値の意味の解釈は医師の書面/説明に依拠し、HRは生活の選択肢整理・次の一歩の設計のみ）→ ④記録はAccordに（同意のもと・あなたのもの）
- **価格構造（初期仮説・要検証）**：
  - HRの伴走・可視化フィー：**¥18,000（定額）**
  - 検査実費：提携クリニックの規定額（HRが立替→総額目安として表示。内訳は開示可能）
  - 表示は「**目安 ¥30,000前後（検査実費込み）**」の形。値付けの主体は分離（検査費＝クリニック、伴走費＝HR）
- **セット「現在地パッケージ」**：外側¥22,000＋内側¥18,000 ＝ ¥40,000 → **セット¥33,000**（LAUNCH_MENU_AND_PRICING と整合）。パッケージ申込時は印象診断分を全額充当（既存ルール維持）
- **再検査（メンテ）**：6ヶ月〜1年ごとの再検査で**レーダーが広がる**体験（/member 実装済みのゴースト重ね・前回比）。継続の理由はゲームでなく「変化の実感」

### 3-3. 第一印象パッケージとの関係

- 独立商品として買える（血液だけでも入れる）
- パッケージ購入者にはオプション提案（「外側を整えた日に、内側の現在地も」）
- **どちらから入っても Accord の同じ旅程に合流する**＝点を線に

## 4. 座組・法務（提携クリニック1社で開始）

- **クリニック（自由診療）**：採血・検査・数値の解釈・診断・（必要時）治療。値付けはクリニック。
- **HR（非医療）**：予約導線・事前案内・立替決済・レーダー可視化・生活の選択肢整理・記録・再検査リマインド。**解釈・診断・受診勧奨はしない**。
- **対価**：CLINIC_PARTNERSHIP の型（月額システム利用料はパイロット¥0＋定額コーディネートフィー。患者数×報酬%にしない）。
- **同意**：血液データ＝要配慮個人情報。取得・表示・クリニックとの共有について**明示同意**（版管理）。「あなたのもの・同意のもと・いつでもやめられる」の3点をUIに明記。
- **広告表現**：効果効能の断定なし／「病気がわかる」と言わない／基準値・改善の約束をしない／受診勧奨しない（選び方記事のトーンと同一）。
- **要弁護士確認**：①検査受診支援の非医療該当性 ②立替＋定額フィーの内訳開示 ③レーダー表示が「診断的表示」にあたらないか ④同意文言。

## 5. 実装計画（段階）

1. **Stage 1（サイト）**：商品ラダーに「内側の現在地」を追加（PricingSection・/packages 詳細・FAQ・llms.txt）。コピーは§2の軸。**恥レイヤーを壊さない**：ホームの主役は第一印象のまま、現在地は第2の扉。
2. **Stage 2（運用）**：提携クリニック1社で試験提供（少数）。予約〜採血〜結果〜伴走セッションのオペレーションを手運用（Accord台帳）で検証。
3. **Stage 3（会員）**：/member の Feed に実データ接続（検査→レーダー更新→次の一歩）。再検査リマインドを LINE で。
4. **Stage 4**：`現在地` を核にした年間メンテプラン（サブスク）検討。B2B（健康経営）はその後の選択肢。

> 一言：Gentsome が「**不調に、名前を**」なら、HRは「**まだ何でもない今に、現在地を**」。同じ血液でも、修理ではなく**予防と自己投資**の物語で売る。外側（第一印象）を持つHRだけが、内側とつないで一本の線にできる。
