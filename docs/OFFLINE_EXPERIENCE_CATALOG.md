# オフライン体験カタログ — 医療行為なしで、現実的に提供できるメンズウェルネス

> His Recoveries が（自社または提携で）オフライン体験として現実的に提供できるものを、
> 法的な線引きで3ゾーンに仕分けたカタログ。※法的助言ではなく設計用の整理。個別スキームは実施前に専門家確認。
> 最終更新: 2026-07-09

---

## 0. 判定の物差し（3つの線）

1. **医行為か** — 診断・治療・投薬・切開・注射・レーザー照射・採血などは医師（医療機関）だけ。HRは提供しない。
2. **資格・届出が要るか** — カット（美容師）、マッサージ（あん摩マッサージ指圧師）等は有資格パートナーの領域。
3. **効果を謳えるか** — 提供できても「治る・予防できる・若返る」等の効果標榜はNG（薬機法・景表法・医師法）。**体験価値（時間・気持ち・整う感覚）で語る**。

```
ゾーンA: 無資格で合法 → HRが直接（または個人パートナーと）提供できる
ゾーンB: 資格・届出が必要 → 有資格の提携パートナーの施術として提供
ゾーンC: 医行為 → 提携クリニックの領域。HRは同行・準備・情報整理まで（紹介対価なし・中立）
```

## 2. ゾーンA — 直接提供できる体験（資格不要）

**見た目・第一印象系（現行の延長）**
- 印象カウンセリング／パーソナルカラー・骨格タイプの見立て／メンズメイク（施術＋再現レッスン）
- 服選び・買い物同行／ワードローブ整理（自宅 or ホテルで）
- 写真撮影（プロフィール・記念）／姿勢・表情・話し方のレッスン
- 香り（フレグランス選び）・小物選び

**リカバリー系（Quiet Sessions の中核候補）**
- 坐禅・写経（寺院提携）／呼吸法・瞑想の時間
- サウナ・温浴同行（施設は公衆浴場側の許可。HRは体験設計と同行）
- 犬・動物と過ごす時間（第一種動物取扱業の施設と提携）
- 自然の中を歩く（森・海・早朝の街）／焚き火・お茶の時間
- 「デジタル断ち」半日リトリート（上記の組み合わせ）

**からだ・習慣系**
- パーソナルトレーニング／ヨガ・ストレッチ（提携トレーナー。医療系資格不要）
- 睡眠環境の整えかた・生活リズムの設計（一般的な情報整理として。療養指導ではない）
- 食事の「型」づくり（一般的な選び方。治療食の指導はしない）

**共通の強み**: どれも匿名・マンツーマンで成立し、効果を約束せず「時間と体験」を売れる。原価は人件費中心で、既存パッケージと同じ運営型（専属＋窓口ひとつ）に乗る。

## 3. ゾーンB — 有資格パートナーの施術として提供

- ヘアカット・ヘアセット・眉スタイリング（美容師）
- フェイシャル・ヘッドスパ等のエステ（強度の高い機器・脱毛は要注意※）
- ネイルケア・ハンドケア
- もみほぐし系リラクゼーション（「治療」「マッサージ効果」を謳わない）

※ 脱毛の注意: レーザー等の永久脱毛は**医行為**（ゾーンC）。エステ光脱毛は法的にグレーが残る領域なので、HRとしては**医療脱毛＝クリニック紹介**に寄せるのが安全。

**HRの役割**: 予約・同席・要望の翻訳（恥ずかしい説明の肩代わり）・体験全体の設計。施術契約は本人⇔サロン。

---

## 4. ゾーンC — 医療。HRは「伴走」まで（提供も斡旋対価もしない）

ニキビ・整形・AGA・ワキガ/多汗症・血液検査・肥満治療・睡眠時無呼吸 など。

**HRが提供できる価値（すべて非医療）**:
1. 悩みの言語化と受診前の整理（何を聞くか・何を伝えるかのメモ作り）
2. 中立な情報提供（選び方の観点。特定院の推奨・ランキングはしない）
3. **同行**（待合の不安・言い出せない要望の翻訳）
4. 前後の伴走（記録・継続の支援）

**守る線**: 紹介手数料を**受け取らない**（保険診療は療担規則で患者紹介対価が明確に禁止。自由診療でも職業安定法・医療広告規制等の論点があり、HRは対価ゼロの中立に徹する）。収益は本人からの伴走フィーで取る。

## 6. 表現ルール（全メニュー共通）

- ❌「認知症予防」「ストレスが治る」「若返る」「痩せる」→ ⭕「犬と過ごす、何も考えない時間」「静けさを取り戻す半日」
- ❌「血液診断」→ ⭕「検査値の可視化（解釈は医師が行います）」
- 医療が関わる体験には必ず「本サービスは医療行為を含みません／診断・治療は医療機関が行います」を明記
- 効果は約束しない。約束するのは**体験の中身・時間・匿名・専属**というプロセス
