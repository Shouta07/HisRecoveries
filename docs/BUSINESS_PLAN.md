# His Recoveries — 事業計画

> 世の中に、自信にあふれた男性を増やし続ける。
> His Recoveries は、男性の回復体験をプロデュースするブランドである。

最終更新: 2026-06-14 ／ 運営: バイタリティデザイン合同会社（Vitality Design LLC）

---

## 0. この計画の前提（読む人へ）

- 数値の財務予測は、まだ一次データが無いため本書では**断定しない**。収益の「構造」と
  前提・仮説として記述し、フェーズが進むごとに実データで埋める。
- フェーズの**順序が最重要**。価値の源泉（原体験 × 編集）で権威と一次データを先に作り、
  その後にパートナー・商品で収益化する。順序を逆にすると「紹介手数料の比較サイト」に
  堕ち、価値が空洞化する。

## 1. ブランド定義

- **ミッション**: 世の中に、自信にあふれた男性を増やし続ける。
- **一行定義**: 男性の回復体験をプロデュースするブランド。
- **本質**: 扱うのは症状ではなく、その奥にある「人に見られている感覚＝男性の自意識」。
- **声**: 一人称・過去形。励まさず、煽らず、売りつけない。半歩先を歩いた当事者として。

## 2. 課題（なぜ存在するか）

- 男性は、人に言えない悩み（汗・におい／ニキビ跡／薄毛／体毛／顔の印象／睡眠と自意識）を、
  ひとりで検索している。相談先がなく、沈黙が長い。
- これは**世界共通の課題**でありながら、日本では「弱音を見せにくい」規範が重なり、
  沈黙が一段深い。
- 既存の選択肢は「商品を売る美容サイト」か「強引営業のクリニック」に偏り、
  **中立に理解を渡す場所が無い**。

## 3. 独自の価値と、堀（Moat）

1. **原体験** — 運営者が当事者として通過した時間。模倣できない信頼の源。
2. **編集** — 中立・非商業の判断と声。理解を翻訳し、相手を保証できる権威。
3. **一次データ** — Recovery Check と改善事例から蓄積する「誰が何に悩むか」の一次情報。
   誰も持っていない資産。
4. **中立性** — 紹介手数料・広告費を取らないこと。これは綺麗事ではなく、
   **巻き込んでも価値が壊れないための構造的防御**。編集が、認証する相手から独立して
   いられる限りにおいてのみ、この事業は成立する。

> 価値の源泉 = 原体験 × 編集 → 信頼 + 一次データ → パートナー（還元・収益化）。
> パートナーは中心だが、核ではない。順序が崩れると堀が消える。

## 4. プロダクト / サービス（現在 → 将来）

### 現在（無料中心・データ収集フェーズ）
- **Recovery Check（無料）** — 30問の自己観察に編集者が手紙で応える。一次データの入口。
- **Recovery Stories（無料）** — 当事者の改善事例アーカイブ（投稿制）。
- **Recoveries Letter（¥500/月・Substack）** — 私的な思いの発信と継続課金。

### 将来（収益化フェーズ）
- **体験パッケージ**（High/Low、後述 §7）
- **Recovery Certified Network** — 認証 + バッジ契約（後述 §6）
- **Recovery Path（理解→行動の SaaS）** — ゲーミフィケーション×図解×システムで、顧客が
  本質から悩みを理解し行動を改善する教育プロダクト。toB（パートナーの顧客教育・
  ホワイトラベル）と toC の両方で SaaS 展開。詳細は
  [`PRODUCT_RECOVERY_PATH.md`](./PRODUCT_RECOVERY_PATH.md)
- **パートナー向けシステム開発** — 現場の一次情報を貯める基盤（後述 §8）
- **共同商品** — 提携パートナーとのプロダクト・ローンチ
- **Recovery Data** — 匿名集計の知見提供（B2B）

## 5. 収益モデル（構造）

| 収益源 | 種別 | 立ち上がり |
|---|---|---|
| Recoveries Letter（購読） | toC・継続 | フェーズ0〜 |
| 体験パッケージ（High/Low） | toC・単発+継続 | フェーズ2 |
| 認証 + バッジ年会費 | toB・継続 | フェーズ1〜2 |
| Recovery Path（顧客教育 SaaS） | toB（ホワイトラベル）+ toC | フェーズ3 |
| パートナー向けシステム開発・運用 | toB・受託+SaaS | フェーズ3 |
| 共同商品（レベニューシェア） | toB2C | フェーズ2〜3 |
| Recovery Data（知見提供） | toB | フェーズ3〜 |

**原則**: 認証そのものでは紹介手数料・広告費を取らない（中立性の維持）。
収益はバッジ年会費・システム・体験・商品・データから得る。認証の中立と、収益源を分離する。

## 6. パートナー戦略 — 認証とバッジ（ミシュラン・モデル）

- **認証**: 5原則（顧客理解／強引営業の禁止／改善データ提供／顧客教育／長期伴走）+
  覆面顧客審査 + 年次更新 + 剥奪事例の公開。
- **バッジ契約**: 認証店は「Recovery Certified」バッジを掲示。ミシュランのように
  **第三者の中立評価が価値を持つ**構造。星の重みは、剥奪の厳しさと公開性が担保する。
- **価値の方向**: 認証は「お金で買えない」。だからこそ、認証された側の集客・信頼に効く。
- **収益**: 認証は無料/低額に保ち、**バッジ年会費・システム・共同商品**で収益化。
  認証の判断と収益を切り離すことで中立を守る。

## 7. 体験パッケージ（High-end / Low-end）

「医療的解決 × サロン通院 × デジタルデトックス」など複数手段を**掛け合わせ**、
単発処置で終わらせず、回復体験としてプロデュースする。

- **Low-end**: デジタル中心。Recovery Check + Letter + セルフケアの設計 + 認証店への
  （手数料を取らない）橋渡し。低価格・高到達。
- **High-end**: 伴走型。医療・サロン・生活設計・デジタルデトックスを組み合わせた
  数ヶ月〜年単位のプログラム。少人数・高単価。
- **設計思想**: 売るのは処置ではなく「整っていく時間」。各手段は認証パートナーが提供し、
  His Recoveries は編集（設計・翻訳・伴走）を担う。

> ⚠️ コンプライアンス必須: 医療を含むパッケージは、医療広告規制・医師法・あはき法・
> 景表法・特商法の確認が前提。医療行為はパートナー（医療機関）が主体で提供し、
> His Recoveries は医療行為・診断・受診勧奨を行わない（既存の免責方針と整合）。
> パッケージ設計の前に専門家レビューを通すこと。

## 8. データ戦略 — 貯めて、還す

```
現場・サイトで一次情報を貯める（Check / Stories / パートナーの改善データ）
        ↓ 編集が匿名化・構造化・意味づけ（学ぶ）
知見が生まれる（誰が何に悩み、何が効いたか）
        ↓ 還元
パートナーの現場改善・共同商品・体験パッケージ・Recovery Data
        ↓
より良い回復体験 → さらにデータが貯まる（ループ）
```

- **パートナー向けシステム開発**を受託し、現場の顧客理解・改善データが自然に貯まる基盤を作る。
  （バイタリティデザインの toB AI・DXシステム開発の本業と直結）
- 貯まったデータは匿名で **Recovery Data** として還元し、商品・パッケージ・認証基準の
  改善に再投資する。これがバイタリティデザインの「実践→集まる→学ぶ→還元」ループの実体。

## 9. 海外展開

- **方針**: 実証は日本、設計は世界。日本で型（Check→理解→改善事例→認証→体験）を作り、
  横展開する。
- **先行収集**: 日本以外の事例・研究も先んじて集め（各原因ページの「日本と海外」比較は
  その布石）、海外パートナーを巻き込む素地を作る。
- **何が国境を越えるか**: 症状のメカニズム（普遍）、自意識のテーマ（普遍）、編集の型（移植可能）。
- **何が現地化を要するか**: 言語、医療・広告規制、文化的な「清潔感」の基準、決済。
- **基盤は実装済み**: `/en` ・hreflang・ロケール対応のコンテンツ層。フル i18n は需要が
  立ってから。

## 10. フェーズ・ロードマップ

### Phase 0 — 発信と収集（現在）｜目標: 信頼と一次データ
- 日本で発信（Threads 中心 + SEO/GEO）。Recovery Check を回す。
- **マイルストーン**: Recovery Check 100件、改善事例 10件、Letter 初期購読者。
- **やらないこと**: 商品を増やす、パートナーを急いで巻き込む。

### Phase 1 — 日本のパートナーを巻き込む｜目標: 認証の確立
- 一次理解を背負った状態で、最初の数院・数名を認証。バッジ契約を開始。
- Recovery Data の初版を内部運用（`/admin/data`）。

### Phase 2 — 体験パッケージ & 共同商品｜目標: toC/toB 収益の立ち上げ
- High/Low の体験パッケージを少数で検証。提携パートナーと共同商品をローンチ。
- コンプラ・レビューを通した上で医療を含む設計に着手。

### Phase 3 — パートナー・システムとデータ・ループ｜目標: スケールする収益
- パートナー向けシステム開発を受託、現場データを基盤化。Recovery Data を B2B 提供。
- ループ（貯める→学ぶ→還す）を仕組みとして回す。

### Phase 4 — 海外｜目標: 世界共通課題への展開
- 海外事例・パートナーを巻き込み、英語圏へ。フル i18n、現地コンプラ、現地認証。

## 11. KPI（北極星と先行指標）

- **北極星**: 「自信を取り戻した」と言える男性の数（回復体験の完了/継続）。
- **先行指標**:
  - Phase 0: Check 完了数 / 完了率 / 改善事例数 / Letter 購読・継続率 / 流入元別CV(UTM)
  - Phase 1+: 認証店数 / 認証維持率（剥奪率）/ バッジ年会費 / 紹介ではなく「信頼」での送客の質
  - Phase 2+: パッケージ単価・継続率 / 共同商品の売上 / パートナーNPS

## 12. リスクと防御

| リスク | 防御 |
|---|---|
| 中立性の毀損（パートナー収益への依存） | 認証と収益源を分離。紹介手数料ゼロ。剥奪事例の公開 |
| 医療・広告の法規制 | 医療はパートナー主体。免責明記。設計前に専門家レビュー |
| 編集（属人）への依存 | 声と基準を文書化（本書・llms.txt・編集ガイド）。段階的に編集チーム化 |
| スケールと編集品質の両立 | 数より質。認証・パッケージは少数精鋭から |
| データの倫理（男性の沈黙） | 匿名化徹底。PIIをダッシュボードに出さない。当事者の尊厳を最優先 |
| 順序の誘惑（早すぎる収益化） | フェーズ・ゲートを守る。Phase 0 の目標未達では Phase 1 に進まない |

## 13. 体制

- **運営**: バイタリティデザイン合同会社（「人と事業の活力を設計する会社」）。
- **現在**: 編集（運営者）1人 + AI・DX システム開発の本業。
- **将来**: 編集チーム、覆面審査員、パートナー開発、システム開発体制へ段階拡張。
- **資産の置き場所**: ブランド（His Recoveries）は中立の編集体。収益事業（認証運用・
  システム・パッケージ）は会社側。編集の独立を構造で守る。
