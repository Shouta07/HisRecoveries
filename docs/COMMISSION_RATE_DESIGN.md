# 対価率 初期数値設計

> `REFERRAL_MODEL_PIVOT.md` §5-2「対価率の初期設定」の実装。
> 二階建て構造：①提携先からのコミッション（B2B・非開示可）＋②顧客が直接払うコーディネートフィー（開示・フラット）。
> 数値は初期仮説。最初の5〜10件の実データで必ず見直す（`CAC_BUDGET_MODEL.md` §7の原則を踏襲）。
> 最終更新: 2026-07-09

---

## 0. 設計原則

1. **逓減式（少額ほど高率・高額ほど低率）**：少額施術でも成立する下限を確保しつつ、高額施術への誘導インセンティブを抑える。
2. **上限キャップ**：1件あたりのコミッション絶対額に上限を設け、「高いものを勧めるほど儲かる」を構造的に防ぐ。
3. **顧客向けは常にフラット**：コーディネートフィーは施術額に連動させない。担当者が施術額でCVに手心を加える理由をなくす。
4. **継続治療は逓減して自然消滅**：初回だけでなく継続分にも小さく乗せるが、期限を切って際限ない抽出にしない。

## 1. 医療パートナー（ゾーンC・自由診療のみ）コミッション率

| 施術・診察の実勢価格帯 | コミッション率 | 備考 |
|---|---|---|
| 〜¥30,000（初診・血液検査等） | **25%**（最低保証 ¥5,000/件） | 少額でも成立させる下限 |
| ¥30,001〜¥100,000（単発施術） | **18%** | |
| ¥100,001〜¥300,000（複数回コース） | **12%** | |
| ¥300,001以上（高額施術） | **8%**（上限 ¥60,000/件） | 過剰誘導防止のキャップ |
| 継続治療（月額処方等・AGA等） | 月額の **10%を6ヶ月まで**、以降0% | LTVは取るが際限なく抽出しない |

## 4. 検算：「薄毛リセットの日」（¥88,000）で整合を確認

```
クリニック初診＋血液検査（実勢）        ¥25,000  ← 顧客がクリニックへ／HRが立替
HRコーディネートフィー（顧客がHRへ）    ¥60,000  ← カウンセリング/同行/スタイリング/撮影/LINE記録
─────────────────────────────
顧客の支払い合計                       ¥85,000 ≈ 目安¥88,000（丸め・提携先により変動）

【HRの受取（別建て・非開示可）】
コーディネートフィー                    ¥60,000
クリニックからの紹介コミッション        ¥25,000×25%=¥6,250
─────────────────────────────
HR総受取                               ¥66,250

HR原価（外部スタイリスト・撮影・管理費 目安30%）  −¥19,900
─────────────────────────────
HR純利益                               ¥46,350（HR受取に対する粗利率 ≈ 70%）
```

**既存の粗利目標（`CAC_BUDGET_MODEL.md`の70%水準）と一致**。案件ごとにこの検算シートで整合を確認する。

## 5. 適用ルール

- 施術額の判定は**提携先の公表価格（税抜）**を基準にする。
- 複数施術が絡む場合は**施術ごとに個別判定**し合算（一律で最高額帯にまとめない＝過大コミッション防止）。
- コミッションは**成約（実施確定）時点で発生**。キャンセル・不成立は発生しない。
- 継続治療の10%×6ヶ月は、**顧客の同意（治療継続の把握への同意）が前提**。無断追跡はしない。
- 全パートナー契約は`REFERRAL_MODEL_PIVOT.md` §1-2の品質基準条項とセットで運用（対価があっても基準未達なら解除）。

---

## 6. 見直しのタイミング

- 最初の**5件成約**でクリニック側の反応（率が高すぎて敬遠されないか／低すぎてHRの粗利が薄くないか）を確認。
- 3ヶ月ごとに`CAC_BUDGET_MODEL.md`の実測データで再計算し、本書を改訂する。
