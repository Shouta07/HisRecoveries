# His Recoveries CAC・予算モデル — 何を何件やると、いくらで何人取れるか

> 目的: 各施策の「実行量 → 効果 → CAC」を試算し、90日の**お金と時間の予算**を策定する。
> 数値は前提（assumption）。実データが出たら §7 の指標で差し替える。虚偽の精度は出さない。
> 最終更新: 2026-07-07

---

## 0. 結論（先に3つ）

1. **この事業はCACに極めて強い。** 1件の粗利（貢献利益）が **約¥105,000**。現金CACが¥20,000前後でも **LTV:CAC ≒ 5:1**。広告を回す余地が非常に大きい。
2. **初期の本当のコストは「お金」ではなく「時間」。** コンテンツ・GEO・取材は現金ほぼゼロだが時間を食う。ただしこれは**複利で効く資産**を作る投資。
3. **90日の目安**: 現金 **約¥180,000**（＋任意の撮影¥80,000）、時間 **週19時間＋提供**。到達目安 **6〜10件成約／売上 約¥90万〜130万**。

## 3. 施策別「実行量 → 効果 → CAC」

### A. コンテンツ（SEO/GEO・/areas）
- **実行**: 月8本（AI補助で1本2.5h＝月20h）
- **効果**: 成熟時 1本≈120visits/月。24本 → 約2,880visits/月 → ×0.5% ≈ **月14件**（9〜12ヶ月目）。**初期90日は1〜2件**（立ち上がり遅い）
- **CAC**: 現金ほぼゼロ（AI月額のみ）。時間は24本で60h（一度作れば複利）
- **性格**: 遅効・激安・最強の複利。**今すぐ仕込む**

### B. ソーシャル（Threads/X/note・リパーパス）
- **実行**: 源泉1本→6投稿。月8源泉＝48投稿／月24h
- **効果**: 認知が育つ3ヶ月目以降で 月200〜600visits → **月1〜3件**。90日は1〜2件
- **CAC**: 現金ほぼゼロ、時間重め。既にやっている自動投稿を"質"で強化

### C. マーケットプレイス（くらしのマーケット/ストアカに①診断を出品）
- **実行**: 出品1＋レビュー10件獲得（初期の手売りで貯める）
- **効果**: 月3件の診断予約 → ×50% ≈ **月1.5件**成約
- **CAC**: 手数料¥3,300/予約 → **成約あたり現金¥6,600**＋設定4h
- **性格**: 即効・低CAC・高意図。ただし**¥150k観の維持に注意**（診断で入れて対面で本体へ）

### D. 有料広告（2ヶ月目〜テスト）
- **実行**: 月¥50,000（CPC¥150→約333クリック）
- **効果**: 訪問→診断1.5% → 5リード → ×50% ≈ **月2.5件**
- **CAC**: ¥50,000 ÷ 2.5 = **現金¥20,000／件**（レンジ¥15k〜40k）
- **性格**: **founderの時間を使わず伸ばせる唯一の手段**。貢献¥105kに対し余裕

### E. 手売り・創業枠（Phase 1・一次ネットワーク＆関係性）
- **実行**: 週3hの個別案内・仲人/知人経由
- **効果**: 90日で **3〜5件**（創業枠¥110k）
- **CAC**: 現金ほぼゼロ、時間1〜2h/件。**最初の実績と声を作る主力**

### F. 取材 → パートナー/紹介
- **実行**: 3ヶ月で10取材
- **効果**: 直接成約は少。**チーム3名確保＋紹介元1〜2**（間接・複利）
- **CAC**: 供給網・信頼への投資（採用CAC・提携の代替）

## 6. 予算（時間）

### 90日・週次の時間配分
| 施策 | 時間/週 |
|---|---|
| コンテンツ（AI補助） | 5h |
| ソーシャル・リパーパス | 6h |
| 取材・パートナー | 3h |
| 手売り・営業 | 3h |
| 分析・管理 | 2h |
| **マーケ小計** | **19h/週（90日で約247h）** |
| ＋提供（1件≈9h：準備・当日・撮影） | 基準10件で約90h |
| **合計** | **約337h／90日** |

**時間CAC（基準）**: マーケ247h ÷ 10件 ≈ **25h/件**（影の値段で¥125,000）。
> 初期は「時間で払う」構造。ただしその時間の大半は**複利資産（記事・観客・チーム）**に化ける。
> **示唆**: founder時間を"複利の仕込み（B/A/F）"に集中させ、**規模化は時間のかからないD（広告）で**買う。
> だから高単価が正義——貢献¥105kが、時間を現金（広告・チーム）に置換する余力を生む。

## 8. 意思決定サマリー（今やること）

1. **時間**: 週19h をB/A/F（ソーシャル・コンテンツ・手売り）に。複利資産を仕込む。
2. **お金**: 90日 ¥180,000。うち¥100,000を**2ヶ月目からの広告テスト**へ（時間を使わず成約単価¥20kを実証）。
3. **判定ゲート**: 90日で6件未満なら前提（特に訪問→診断CVR）を疑い、オファー/導線を再設計。10件超なら広告を月¥200kへ増額。
4. **capacity**: 需要より**提供能力（solo＋チーム）が先に限界**。だから価格を上げ、チームを増やし、1件の粗利で買収を回す。
