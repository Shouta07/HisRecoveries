## 1. 一行の事業定義

**男性が「言えない見た目・体の悩み」を、恥をかかず・迷わず解消できるように、
医療・サロン・生活の体験を人＋AIで束ねて伴走する、完全匿名のウェルネス・コンシェルジュ。**

運営: バイタリティデザイン合同会社（VD）。ブランド: His Recoveries（HR）。

### 確定した経営判断（2026-07-09・`FUTURE_STRATEGY_HORIZON.md`§5）
1. **入口は「恥の解消」**。成長期に「自己投資・最適化」の言語を併走（入口は変えない）。
2. **HR＝対顧客／VD＝対業界を徹底**。契約・請求・名刺・LPを2系統に分離。顧客にVDを見せない／業界営業でHRの中立ブランドを道具にしない。
3. **物理拠点は持たない**（間借り・提携空間・出張で代替。Marriottモデル死守）。
4. **横展開（女性/海外/法人）は国内男性でH2の型が固まるまで着手しない**。
5. コーディネーター内製人数のみ**保留**（稼働率ベースの発火条件で後日決定）。

## 2. 解く課題（なぜ存在するか）

- **沈黙する500万人**: AGA自覚915万人・未行動500万人。男性は身体/外見/メンタルで援助を求めにくい（`MARKET_THESIS.md`§2）。原因は性格でなく「恥に配慮した入口の欠落」という構造。
- **市場は巨大で成長中**: グローバル男性H&W $1.42T→$2.88T（2030, CAGR12%）。日本の該当6領域だけで概算1,000〜2,000億円（`MARKET_THESIS.md`§1）。
- **縦割りで"あいだ"が空席**: 医療・サロン・ジムは各自の商品しか勧められない。横断して束ねる中立の伴走者がいない。
- **社会的意義**: 見た目の悩みは、男性が最も相談しやすい"表層の入口"。ここから孤立・メンタルの支援へ繋ぐ導線は公衆衛生的にも意味がある。→ 「儲かる」と「社会課題解決」が同じ動作で成立する。

## 4. HRだけの価値（模倣不能性）

**人間コーディネートの価値（AIに出せない）**: 言われていないことを聞く／信用の移転／その場の代弁・交渉／責任を引き受ける。
**HRだけの価値（他の人間コンシェルジュにも出せない）**: 当事者性／構造化された中立（＝下記の自制装置）／恥への解像度／医療×サロン×生活を横断する唯一の立場／匿名前提の業務設計。

> 抽象化の出典（`COMPETITIVE_LANDSCAPE_CONCIERGE.md`）: 統合チーム=高単価(Fountain Life)／検査→人が翻訳(Lifeforce)／対面は逆張り差別化(Gameday)／立替+フィーの座組は実務確立(医療ツーリズム)／中立メディアが判断軸を売る(NERO・NEWT)／価格は設計時間の長さ(NEWT Bespoke)。**これらを「恥・匿名」の一点に統合しているのがHRの独自性**で、全部を満たす競合は国内外に不在。

## 5. 収益構造（儲かる仕組み）

### 二階建てエンジン
```
エンジン1: His Recoveries（B2C＋B2Bコミッション）
  顧客フィー ＋ 提携先コミッション → 粗利率70%水準
エンジン2: VD システム事業（B2B・本業）
  HR提携先へ業務システム・AI導入を受託 → HRのパートナー網がVDの営業パイプに
```
**HR単体で黒字化できる設計にしつつ、VDのシステム受託が乗ると1パートナーのLTVが跳ねる。**

### 対価率（`COMMISSION_RATE_DESIGN.md`）
- 医療(自由診療のみ)は逓減式: 〜3万=25% / 〜10万=18% / 〜30万=12% / 30万超=8%(上限¥6万)。継続治療は月額10%×6ヶ月で終了。
- サロン一律20%。顧客向けコーディネートフィーは施術額に連動しないフラット（¥15,000〜80,000）。

### 粗利率・原価（HR純受取ベース＝GMVでなく純額で管理）
| SKU | 粗利率 | 主原価 |
|---|---|---|
| 印象診断 | 85〜90% | 人件時間のみ |
| Quiet Session | 65〜75% | 施設・体験費¥8-12k |
| 単発パッケージ | 65〜70% | 外部チーム¥20-35k |
| ハイエンド | 70〜75%（時間込55-60%） | 外部チーム複数回＋founder時間 |
| 継続コミッション | 〜95% | ほぼゼロ（システム追跡） |

- 月次固定費 約¥6〜8万（AIツール/インフラ/保険/顧問）。**月2件の単発パッケージで固定費回収**＝固定資産を持たない軽さ。
- 財務は必ず**純額表示**で見る。GMV（医療費立替込み）で見ると粗利率が見かけ上15〜25%に落ちるが、利益額は変わらない罠（`CAC_BUDGET_MODEL.md`／立替＝パススルー）。

## 6. 法務の座組（法律をくぐる構造）

- **医療は自由診療のみ**。保険診療への送客対価は取らない（療担規則）。
- **座組は「立替受領＋固定コーディネートフィー＋実績非連動の要素を残す」**。医療ツーリズム各社が長年合法運用している実務（`COMPETITIVE_LANDSCAPE_CONCIERGE.md`§2）。
- **合法を分ける4テスト**: ①対価が患者数に過度連動しない ②HP取り分に役務の実体がある ③内訳が開示可能 ④クリニックが自分で値付け（`REFERRAL_MODEL_PIVOT.md`）。
- **自制装置＝法的安全弁**: 逓減コミッション・掲載は買えない・覆面調査・少数精鋭。これを外すと「患者紹介ビジネス」に堕ち、法・信頼の両方が壊れる。
- ⚠️ 実行前に医療法に強い弁護士のレビュー必須。資金決済法（立替送金の規模）・医療広告ガイドライン（クリニック名を出す販促）も個別確認。

## 7. マーケティング戦略

土台は既存3本（`MARKETING_SEO_GEO.md`／`AI_MARKETING_PLAYBOOK.md`／`B2C_RESONANCE_DESIGN.md`）。今回の学びで3点を上乗せ：
1. **恥の正常化を全ファネルの第一声に**（hims/Gamedayの脱スティグマをHR語で。「口に出さないだけで、同じ悩みの人は多い」）。
2. **検査・診断を"広告"にする**（Lifeforce型。印象診断¥22,000を集客商品として単体で押す）。
3. **成果は"匿名の記録"で語る**（顔を出さない変化の記録＝ビフォーアフター規制の回避×信頼×GEOで引用される一次情報）。

チャネル優先度: 手売り/創業枠 → マーケットプレイス(診断を出品) → SEO/GEO(Library) → 広告テスト（CAC¥20,000目安、貢献利益に対し約5:1）。

## 8. 採用戦略

**原則: 「揺れる瞬間」を扱える人だけ採る。残りはAI＋業務委託。**
- Phase1: founder＋AI＋業務委託3職種（メイク/スタイリスト/撮影を**取材経由で**委託化＝採用コスト≒0）。
- Phase2の最重要採用＝**コーディネーター1号**: 当事者性／翻訳力（医療⇄生活）／守秘の体質。出身プールは①HR顧客卒業生 ②看護師・医療事務 ③美容部員・スタイリスト。見極めは**同行のロールプレイ**で。
- ブランドで採る: `/manifesto`のJoin us・`/partners`が入口。取材→業務委託→社員の順で段階的に。いきなり雇わない。

## 9. パートナーセールス戦略（2入口→1パイプライン）

現在の接点2つを、同じパイプの2入口として設計：
```
入口A: 取材（共感ベース・露出と被リンクを先に渡す）
入口B: VDシステム商談（実利ベース・業務課題を先に解決）
        ↓ 関係構築
   提携提案（対価契約・COMMISSION_RATE_DESIGN の率）
   ピッチ一言: 「広告費（前払い・水物）を、成果報酬（後払い・確実）に置き換えませんか」
        ↓ 送客実績 → 四半期レビュー
   ├→ VDシステム受託へ拡張（LTVが跳ねる）
   └→ 満足度データを次の営業の実績資料に
```
- クリニックの損得: 広告費高騰の中、HRのコミッションは**成約時のみ発生**＋来る顧客は期待値調整済みでミスマッチ・ドタキャンが少ない。
- 入口が2つあるので、片方で断られても関係が切れない。
- 少数精鋭を維持（量産型の患者紹介と一線＝法的リスク低減も兼ねる）。
- LTV判断は「送客コミッション＋VDシステム開発・保守」の合算で（HR単体で見ない）。
- 実務テンプレは `PHASE1_TRANSITION.md`（メール文面）・`INTERVIEW_PROGRAM.md`（取材ファネル）。

## 10. なぜ続くか（三方よしの一段要約）

```
顧客   : 恥の壁を越えられる（社会課題の解消）→ 高い納得度で払う
提携先 : 広告より安く良質な顧客＋現場DX → 対価を払う理由がある
HR/VD  : フィー(粗利70%)＋コミッション＋システム受託の三重取り／固定費が軽く月2件で黒字
         人は「揺れる瞬間」だけ、残りAI → スケールしても品質が崩れない
```
**搾取する相手がいないから続く。** 自制装置（逓減・掲載を売らない・覆面）を外した瞬間に壊れる。

## 11. リスクと防御

| リスク | 防御 |
|---|---|
| 患者紹介対価の法規制 | 自由診療限定・立替+固定フィー・少数精鋭・弁護士レビュー |
| 「利益のために勧めている」疑念 | 対価の開示・掲載は買えない・逓減で高額誘導を抑制・覆面調査 |
| 医療広告/薬機法/景表法 | 効果を謳わない・匿名記録で成果を語る・医療はパートナー主体 |
| 属人（founder1人） | AIで業務を機構化・声と基準を文書化・取材で委託先を先に確保 |
| 品質とスケールの両立 | 「揺れる瞬間だけ人」の棲み分け・満足度連動ペナルティ |
| 旧方針との混乱 | 本書を最上位とし、旧BUSINESS_PLAN/MARKET_THESISは読み替え |
