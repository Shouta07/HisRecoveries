# キュレーション編集プレイブック

> 運営: バイタリティデザイン合同会社 / His Recoveries
> 目的: 「取り扱う領域」を、**自分たちの中立な解説（主）＋各クリニックの解説の引用（従）＋出典リンク**で構成する、信頼されるキュレーションメディアとして運用するための指針。
> 関連実装: `src/lib/areas.ts`（原文）, `src/lib/citations.ts`（引用）, `src/app/areas/[id]/page.tsx`（記事ページ）

---

## 0. 立ち位置（最初に固定）

- 何のためか＝**ユーザーが原因を理解 → 信頼 → 予約**へ進むための「一次理解」。SEO集客＋信頼形成。
- 差別化＝**中立**。特定院を推奨しない／紹介手数料ゼロ／複数ソースを並列。アフィリエイトまとめサイトと一線を画す。

## 1. 法務の土台（外すと全部崩れる）

### 1-1. 引用の要件（著作権法32条）
全て満たすこと：
- [ ] 公表済みの著作物である
- [ ] **主従関係**：自分の解説が主、引用は従（量・質とも）
- [ ] 明瞭区別：引用は「」/ blockquote で本文と区別
- [ ] 出典明示：媒体名＋URL
- [ ] 必要最小限の抜粋（**全文転載は禁止**、必ずリンクで送る）
- [ ] 改変しない

#### 「引用」と「参考リンク」を混同しない（実装で強制済み）

**原文を確認せずに引用文を書いてはいけない。** うろ覚え・要約・言い換えは「改変しない」
要件に反し、引用として違法になる。したがって `src/lib/citations.ts` の `Citation` 型は
判別可能なユニオンになっており、

- `quote`（原文からの抜粋）を書くなら `verifiedAt`（原文を確認した日）が**必須**
- `verifiedAt` が無ければ `quote` は**型エラー**

つまり「未確認の引用文」はコンパイルが通らない。この仕組みは意図的なので外さないこと。

| | 使う場面 | 表示 | 法的性質 |
|---|---|---|---|
| `quote` + `verifiedAt` | 原文を開いて一字一句確認した | 「」付き blockquote ＋ 原文確認日 | 引用（32条の要件を満たす必要あり） |
| `note` のみ | 出典を示したいが原文を逐語確認していない | リンク＋中立な一言 | 引用ではない（参照の明示） |

迷ったら `note` のみにする。**専門性は、引用文の有無ではなく出典の質（§3）で担保する。**

> 補足: 学会ガイドライン等の PDF は、リンクで送るのが原則。図表の転載はしない。

### 1-2. 医療広告ガイドライン
- 「治る」「効果」などの**断定・効果保証はしない**。
- **体験談の引用は要注意**（医療広告で体験談は原則NG）。引用は「メカニズム・一般的知見」中心に。
- 治療成果の宣伝に見える構成にしない。

### 1-3. ステマ規制（景表法）
- 金銭関係があれば必ず明示。**手数料ゼロ＝「PRではない」と言える**のが強み。

### 1-4. 関係構築
- 引用は許諾不要だが、出典元へ「引用しました」一報を入れると安全＆将来の提携につながる。

> 公開前に一度、弁護士レビューを推奨。

## 2. 記事の型（1本の作り方）

```
テーマ選定（検索需要）
 → 一次ソース収集（信頼できる出典）
 → 自分の解説を書く（主：areas.ts）
 → 各ソースから短く引用（従：citations.ts）
 → 出典明記・リンク
 → 医師監修
 → 公開（/areas/[id]）
 → 内部リンク（取り扱う領域 → Recovery Journey → 予約）
```

**原文（主）の標準構成**（`areas.ts` の1領域）：
1. lead（1〜2文の要約）
2. 何が起きているか
3. なぜ起きるのか（メカニズム）
4. 変えられること・変えにくいこと
5. 受診の目安（whenToSee）

**引用（従）**（`citations.ts` の1件）：`{ source, url, quote }`
- source：出典名（クリニック・学会・公的機関）
- url：元記事の正規URL（別タブ・`rel="nofollow noopener"`）
- quote：短い抜粋（1〜2文）

## 3. 情報源の設計

- 領域ごとに **3〜7の良質ソース**を選び、1院に偏らせない。
- 信頼度の優先順位：**公的機関・学会 > 専門クリニックの監修記事 > 一般記事**。
  - 例：厚労省 e-ヘルスネット、各学会の診療ガイドライン、専門クリニックの医師監修ページ。
- 出典マスター（下記テンプレ）で管理。

## 4. 公開チェックリスト（1本ごと）

- [ ] 自分の解説が主（引用より長い・オリジナルな価値がある）
- [ ] 引用は「」/blockquoteで明確に区別、必要最小限
- [ ] 出典名＋URLを明記、リンクは別タブ・nofollow
- [ ] 効果・断定・体験談を使っていない
- [ ] 医師監修を通した
- [ ] 特定院を推奨していない（複数を並列・中立）
- [ ] 免責文を表示
- [ ] 内部リンク（予約導線）を設置

## 5. 技術・スケール

- Phase 1（今）：`areas.ts`＋`citations.ts` を手動更新。少数を丁寧に。
- Phase 2：ヘッドレスCMS（microCMS等）へ移行し、「領域→記事→引用（出典・URL・抜粋）」をスキーマ化。非エンジニアでも更新可能に。
- 構造化データ：Article / FAQ schema を付与。出典リンクは `rel="nofollow noopener"`。
