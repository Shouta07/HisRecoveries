# 第一印象パッケージ — 現場運用マニュアル（オペレーション資料）

> 運営: バイタリティデザイン合同会社 / His Recoveries
> 対象パッケージ: `first-impression`（`src/lib/packages.ts`）
> 商品定義: 「印象を、再現できる型に。」 1ヶ月 / ¥38,000〜 / テーマ＝顔・自意識
> ジャーニー: 肌・印象の診断 → メイク＋服選び＋撮影 → 1ヶ月後の再撮影

このドキュメントは、商品ページ上の3ステップを **現場でそのまま回せる手順** に
落とし込んだものです。担当者が初回でも、これ一枚で予約〜納品〜ふりかえりまで運用できることを目的とします。

---

## 0. 大前提（ブランド・コンプライアンス）

現場の全工程で、次の原則を崩さないこと。表現・案内・記録すべてに適用します。

| 原則 | 現場での意味 |
| --- | --- |
| 完全匿名 | 本名・顔・実年齢は受け取らない／残さない。会員IDで運用。撮影データも本人管理を基本とする。 |
| 完全守秘義務 | 担当・パートナー全員がNDA。セッション内容・写真・悩みは外部共有しない。 |
| 中立 | 物販・医療の紹介手数料はゼロ。「売らない」。必要なら情報を中立に並べるだけ。 |
| 医療免責 | 本パッケージは医療行為ではない。肌・体の医療的判断はしない。必要時のみ連携医療機関を中立に案内。 |
| 言い切らない | 「効果がある」「若返る」「モテる」等の断定・効果訴求はしない。完了形（〜できました）も使わない。 |

**NGワード例**: 「効果」「若返り」「-10歳」「モテる」「必ず」「改善されます」
**OKの言い回し**: 「印象を再現できる型に」「自分で整えられる状態に」「中立に並べる」「選択肢を持つ」

---

## 1. このパッケージが提供するもの / しないもの

- **提供する**: 第一印象（主に顔まわり・服・写真）を、本人が **自分で再現できる「型」** にして持ち帰ってもらう体験。診断 → 実践 → 1ヶ月後の再現確認、の1本の線。
- **提供しない**: 美容医療、整形・施術の斡旋、物品販売、ビフォーアフターの効果保証。

成果物は「変わった写真」ではなく「**再現手順（型）＋本人が撮った/撮られた素材**」。

---

## 2. 対象者と適合チェック

商品ページ上の対象: 「写真・人前が苦手／老け見えが気になる方へ。」

予約受付時に、専属担当が以下を確認（LINE/アプリのヒアリングで）。

**適合**
- 写真・人前・第一印象に自意識がある
- 自分で再現できる型を求めている（依存ではなく自立）

**要・事前調整 / 連携案内**
- 医療的な肌トラブル（強い炎症・疾患の自覚）がある → 施術前に連携医療機関を中立案内（手数料ゼロ）
- 撮影の顔出し可否 → 後述の「匿名・撮影データ運用」で必ず確認

| 区切り | 名称 | 形式 | 標準所要 | 主担当 |
| --- | --- | --- | --- | --- |

## 4. セッション別・現場手順

### Day 0 — 肌・印象の診断（現在地）

**目的**: いまの第一印象を、本人と担当が同じ言葉で見られるようにする（評価・ダメ出しではない）。

**進行（45–60分）**
1. 守秘・匿名の確認（2分）— NDA・データの扱い・顔出し可否を口頭で再確認。
2. 現在地ヒアリング（15分）— 何が・どんな場面で気になるか（写真、対面、清潔感、老け見え 等）を言葉に。
3. 中立の見立て（20分）— 肌・髪・服・姿勢・表情を「良し悪し」でなく「特徴」として並べる。医療判断はしない。
4. 1ヶ月のゴール設定（10分）— 「再現したい型」を1–2個に絞る（例: 平日の自分で再現できる清潔感のある印象）。
5. 次回準備の案内（5分）— Session 1の持ち物・服の方向性・スケジュール確定。

**担当チェックリスト**
- [ ] 会員IDで記録（本名・顔写真をシステムに残していない）
- [ ] 顔出し可否・撮影データの扱いを本人と合意
- [ ] 医療的トピックがあれば「中立案内」フラグを立てる（斡旋はしない）
- [ ] ゴールを本人の言葉で1–2個に確定

**禁止**: 効果・改善の約束、商品の推奨販売、医療的な診断・断定。

---

### Session 1 — メイク＋服選び＋撮影（中核）

**目的**: 型を「実際に手を動かして」体験し、本人が再現できる状態に近づける。

**所要 180–210分 / 役割分担**

| 時間 | 内容 | 主担当 |
| --- | --- | --- |
| 0–15分 | 受付・守秘確認・本日のゴール共有 | 専属担当 |
| 15–60分 | スキンケア＆メイク（本人の手で1回再現まで） | メイク |
| 60–105分 | 服選び（手持ち＋拠点サンプルで「型」を組む） | スタイリスト |
| 105–165分 | 撮影（型あり／なしの素材を本人管理前提で） | フォトグラファー |
| 165–210分 | 型の言語化（手順メモ・買い足し不要リスト） | 専属担当 |

**運用の肝**
- メイクは「やってあげる」ではなく「**本人が1回自分でできる**」まで。手順を分解して渡す。
- 服は売らない。手持ち中心に、足りない分のみ **中立に** 候補を並べる（特定ブランド誘導・手数料なし）。
- 撮影は「盛る」ためではなく、**再現の基準**を残すため。データは本人管理を基本とする。

**担当チェックリスト**
- [ ] 本人が自分でメイクを1回再現できた
- [ ] 服の「型」を最低1パターン、言葉と写真で固定
- [ ] 撮影データの受け渡し方法を本人と合意（後述）
- [ ] 効果・断定表現を使っていない

---

### 型の納品（Day 7–10・非同期）

Session 1の内容を、本人が1ヶ月再現するための **マニュアル** にして納品。

**納品物（デリバラブル）**
1. スキンケア＆メイク手順（写真付きステップ・所要時間つき）
2. 服の型（組み合わせ表／手持ちで成立する形）
3. 撮影の自己再現メモ（光・角度・距離の目安）
4. 1ヶ月後の再撮影に向けた、ゆるい再現チェック（〜すべき、ではなく目安）

> 文言は「整える／再現する／選択肢を持つ」基調。「改善した」「効果」は使わない。

---

### Session 2 — 1ヶ月後の再撮影（ふりかえり）

**目的**: 1ヶ月、自分で型を再現できたかを、本人と一緒に確認する。比較は「優劣」でなく「再現度」。

**進行（60–90分）**
1. 守秘確認（2分）
2. 再撮影（同条件で素材を残す。Day 0/Session 1と同じ基準で）
3. 再現度のふりかえり（本人の言葉で。担当はジャッジしない）
4. これからの選択肢の整理（続ける／別パッケージ／何もしない、を中立に並べる）

**担当チェックリスト**
- [ ] 同条件で再撮影できた
- [ ] 本人が「自分で再現できた範囲」を言語化できた
- [ ] 次の選択肢を中立に提示（押し売りしない／「何もしない」も提示）

## 6. 匿名・撮影データ運用（最重要）

第一印象＝顔まわりを扱うため、データの扱いが事業の信頼の核。

- **本人管理が原則**: 撮影データは可能な限り本人の端末/本人管理クラウドへ。社内に顔データを残さない設計を第一候補とする。
- **社内保管が必要な場合**: 会員IDのみで管理し、保管期間と削除期限を本人と事前合意。期限到来で削除。
- **共有禁止**: SNS・実績紹介・パートナー間での顔写真共有は、本人の個別書面同意がない限り一切しない。
- **同意の記録**: 顔出し可否・保管可否・期限を、会員IDに紐づけて記録（本名とは結びつけない）。
- **削除請求**: 本人からの削除依頼は即応。完了を本人に通知。

## 9. リスクと対応

| リスク | 予防 / 対応 |
| --- | --- |
| 効果を期待されすぎる | 受付・Day 0で「再現できる型を持ち帰る体験」と明言。断定しない。 |
| 医療領域への踏み込み | 医療的判断はしない。必要時のみ連携医療機関を中立案内（手数料ゼロ）。 |
| 顔データの漏洩懸念 | 本人管理を原則化。社内保管は会員ID＋期限削除。NDA徹底。 |
| パートナーの中立性崩れ | 固定委託費・物販誘導禁止を契約で明文化。 |
| 当日キャンセル | 事前決済＋キャンセルポリシーをNDA時に提示。 |

## 10. KPI / ふりかえり（押し売りしない範囲で）

- 完遂率（Day 0 → Session 2 まで到達した割合）
- 「自分で再現できた」と本人が言語化できた割合（自己申告・効果指標ではない）
- 次の選択肢への自然な継続率（強制しない／「何もしない」も正解）
- パートナー稼働あたり粗利

> いずれも「煽らない・断定しない」。本人の主観と運用効率の指標であって、効果の証明には使わない。
