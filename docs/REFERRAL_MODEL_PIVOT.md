# 商業モデルの転換 — 送客対価あり × 高単価 × AI/人間の棲み分け

> 意思決定: 「紹介手数料ゼロ・中立」を**堀としては使わない**方針に転換する。
> 送客の対価を取る代わりに、**別の堀（キュレーション品質・人間の判断・体験の一貫性）で高単価と納得度を作る**。
> ⚠️ この決定は `BUSINESS_PLAN.md` §4「独自の価値と堀」・`MARKET_THESIS.md` Lever 1 と矛盾する。
> 該当箇所は本書を正として読み替える（両ドキュメントは後日改訂 or 廃止判断）。
> 最終更新: 2026-07-09

---

## 0. なぜ転換するのか（正直な整理）

「紹介手数料ゼロ」は強い堀でしたが、代償も大きいものでした：
- パートナー開拓が遅い（金銭的インセンティブなしで口説く必要がある）
- 収益化がPhase 2〜3まで先送りされる設計（Check100件のゲート等）
- 立替払い・純額表示など、**運用が複雑**（前回議論した座組）

紹介手数料を取る決断は、**スピードと運用のシンプルさを買う**判断です。代わりに、堀を「中立性」から**「キュレーションの質と人間の判断」**へ移す。これは業界的にも一般的な形（美容医療の紹介・コーディネート業は自由診療において合法かつ広く存在する）で、無理な座組ではありません。

## 1. 新しい商業構造

### 1.1 収益モデル
```
パートナー（クリニック・サロン）から、成約・送客に対する対価を受け取る
  ├─ 基本形: 定率コミッション（総額の15〜25%を目安。前回の業界水準と整合）
  ├─ または: 固定紹介料 + 低率の成果連動（過度な誘導インセンティブを抑える）
  └─ 顧客への価格は「まるっと1本」で提示（NEWT/Otonami型のUX）
```

### 1.2 契約の作り替え
`中立業務提携協定_ひな型.md` の**第3条（金銭の不授受）を撤廃**し、新規に以下を明記した契約に置き換える：
- 対価の金額・料率・支払サイト
- **品質基準（旧5原則を維持）** — 対価を払っても基準未達なら契約解除できる旨
- 医療広告ガイドライン・景表法遵守（変更なし）
- 覆面調査・年次更新の権利（HRが継続的に品質を監査できる条項は残す）

> 契約類型は「紹介契約」または「代理店契約」相当（従来の"業務提携"ではなく、対価が明記された通常の商取引契約）。**保険診療に紐づく紹介は引き続き対象外**（療担規則の射程は残るため、自由診療のみが対象）。

### 1.3 まだ避けるべきこと
- **保険診療への送客対価**（療担規則違反・不可逆リスク）
- **患者紹介ビジネス的な量産スキーム**（2014年規制強化の標的パターン＝質を問わない大量送客）→ **少数精鋭のキュレーションを維持することが、法的リスク低減にも直結する**
- 医療広告ガイドラインに抵触する表現（効果保証・誇大・比較優良表示）

## 2. 「高単価かつ納得度」をどう作るか

対価を受け取る以上、**「HRは自分の利益のために勧めているのでは」という疑念**が新たな脅威になります。ここを潰す設計が要ります。

### 2.1 透明性を"隠さない"ことを差別化にする
「紹介料ゼロ」の代わりに、**「対価を受け取っていることを、隠さず開示する」**という誠実さを新しい信頼の軸にする。
> 「His Recoveries は、提携先から紹介の対価を受け取っています。ただし掲載は買えません——独自の基準を満たした先だけと提携します。」
不動産仲介・保険代理店・多くの優良コンシェルジュサービスも同じ構造で信頼を得ている。**「対価がある」こと自体は問題ではなく、「対価が判断を歪めていない」ことを証明できるかが本質。**

### 2.2 掲載は買えない、を維持する
対価は**送客の結果**に対して発生するのであって、**掲載枠を売る**わけではない。既存の5原則（顧客理解・強引営業の禁止・改善データ提供・顧客教育・長期伴走）による審査は**そのまま維持**し、基準を満たさない相手からは対価があっても提携しない。

### 2.3 品質を担保する4つの仕組み
1. **覆面調査の継続**（年次更新・剥奪も継続）
2. **満足度に連動したペナルティ**：低評価が続くパートナーは対価率を下げる／契約解除
3. **定率よりは「定額＋低率」を優先**：過度に高額な施術へ誘導するインセンティブを薄める
4. **顧客への事後アンケート**を制度化し、「勧められて良かったか」を継続的に検証・公開実績にする

### 2.4 高単価を支えるのは、結局「人間の判断」
前回の整理の通り、対価構造が変わっても**信用の移転・その場の代弁・恥への配慮**という人間コーディネートの価値は消えません。**対価はHRの収益構造であって、顧客が払う対価の理由ではない。** 顧客に見せる価値訴求は変えない：「専属が、あなたの側に立って選ぶ」。

## 3. AIと人間の棲み分け設計

原則: **「揺れる瞬間」の前後はAI、揺れる瞬間そのものは人間。**

```
① 受付・一次ヒアリング        [AI主導・人が監修]
   匿名フォーム/チャットで状況を聞き取り、AIが要点を要約・仮説化
   → 人間が会話前にレビューし、聞くべき核心を用意する

② 本カウンセリング（初回対話） [人間のみ・core]
   言われていないことを聞き取る、信頼を作る、方針を一緒に決める
   → 自動化しない

③ パートナー選定              [AI提案・人間が最終判断]
   AIが専門・価格帯・空き状況からマッチ候補を提示
   → 最終的にどこを勧めるかは人間が決める（対価の大小で歪めない人間のチェック）

④ 日程調整・事務手続き        [AI自動化]
   予約・リマインド・支払い・書類 — 判断を要さない業務は全て自動化

⑤ 同行・現場での立ち会い      [人間のみ・core]
   不安の察知、その場での代弁・交渉、心理的な伴走
   → 自動化しない。ここがHRの対価の"本体"

⑥ アフターフォロー            [AI下書き・人間が仕上げ]
   状況確認メッセージ・満足度アンケートはAIが起案
   → ネガティブな兆候が出たら人間が直接連絡

⑦ 品質管理・パートナー審査    [人間のみ・core]
   覆面調査・契約継続可否の判断・剥奪の意思決定
   → 対価が絡む領域だからこそ、人間の説明責任が必須

⑧ 発信・マーケティング        [AI主導・人間が承認]
   AI_MARKETING_PLAYBOOK.md の方針を維持（変更なし）
```

**判断基準**: その業務を間違えると「顧客の恥・信頼・お金」が傷つくものは人間。判断を要さない・後戻りできる業務はAI。
