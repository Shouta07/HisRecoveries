# メンズウェルネス市場 — 需要と供給ギャップの分析

> 仮説「需要はあるのに男性特化サービスが少ない」を実データで検証。
> 結論：仮説は**半分正しく半分古い**。"施設"は急増中だが、"横断して伴走する層"は依然空白。
> 最終更新: 2026-07-09（公開情報ベース。市場数値は集計範囲で振れ幅あり）

---

## 0. 結論（3行）

1. **需要は本物・急成長**：メンズ化粧品は5年で1.8倍、脱毛は4年で1.8倍。年5〜20%成長（出典下記）。
2. **供給ギャップは"施設の数"ではなく"体験の質"に移った**：クリニック・サロン・専門店は既に急増中。**足りないのは「どこに行けばいいか分からない」を解く横断ナビ層**。
3. **HRの空席は健在**：施設が増えるほど「選べない迷子」が増える＝HRの伴走価値はむしろ上がる。

## 3. なぜ"横断ナビ層"だけ空席のままか（構造的理由）

各プレイヤーは、自分の箱しか勧められない：
```
クリニック → 自院の施術を勧める（他院・非医療は勧めない）
サロン    → 自店のメニューを勧める
D2Cブランド → 自社製品を勧める
比較メディア → 広告費を払う先を上位に出す（Wirecutter型）
```
- **箱が増えるほど、横断して"あなたにはどれが要るか"を中立に整理する必要が増す**が、それは既存プレイヤーの誰も収益構造上できない（自社商品を否定できない）。
- 「恥・匿名」への配慮も、対面前提の箱型ビジネスには埋め込みにくい。
- → **迷子・恥・横断の3点セットは、独立した伴走層でしか解けない。ここがHRの空席。**

## 4. 「男性特化サービスが少ない」の正確な言い直し

| よくある言い方 | 実態 | 正確な言い直し |
|---|---|---|
| 男性特化の**施設**が少ない | ❌ もう古い（急増中） | 施設は足りてきた |
| 男性の**悩みに寄り添う入口**が少ない | ✅ 正しい | 恥・匿名に配慮した入口は依然希少 |
| **横断して選び・束ねる**サービスが少ない | ✅ 正しい（ほぼ皆無） | 中立の伴走ナビ層は空白 |
| **見た目以外**（心・習慣・眠り）まで扱うメンズウェルネスが少ない | ✅ 正しい | 統合型は不在（`COMPETITIVE_LANDSCAPE_CONCIERGE.md`の結論と一致） |

## 5. HRへの示唆（この分析が意味すること）

1. **HRは「箱を作る」勝負に参入してはいけない**。クリニック・サロンの箱は既に飽和に向かっている（レッドオーシャン化中）。HRは**箱を作らず、箱を横断する層**に居続けるのが正解（Marriottモデル＝固定資産を持たない方針の裏付け）。
2. **"迷子"の増加は、HRにとって追い風**。供給（箱）が増えるほど「どれを選べばいいか分からない」人が増え、ナビ需要は拡大する。競合が増えることがHRの市場を広げる、珍しい構造。
3. **恥・匿名は依然として最大の差別化軸**。業界メディア自身が「恥ずかしさの払拭がカギ」と言っている＝まだ誰も解けていない証拠。
4. **"見た目"を入口に、心・習慣まで広げる統合が白地**。メンズ美容の箱は「見た目」で止まっている。HRのウェルネス（Quiet Session等）への拡張は、供給ギャップの深い側を突く。
5. **タイミングが良い**：文化転換（2020-2024）で需要は顕在化済み、箱の供給も出揃いつつある"今"が、横断ナビ層が刺さる瞬間。早すぎず（需要待ち）遅すぎず（箱が飽和して淘汰が始まる前）。

## 6. 一枚まとめ

```
需要:  ◎ 急成長（5年1.8倍・年5〜20%）・文化転換で顕在化済み
供給(箱): △ もう飽和に向かう（クリニック/サロン/D2C 急増）
供給(ナビ): ✕ ほぼ空席 ← 迷子・恥・横断・統合を解く層がいない
────────────────────────────────
HRの立ち位置: 箱を作らず、箱を"横断して束ねる"中立の伴走層。
           箱が増えるほど有利になる、数少ないポジション。
```
