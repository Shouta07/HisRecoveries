# His Recoveries 立ち上げ設計書 — 高単価・緊急・支払力のある顧客に売る

> 方針: **基本高単価**。緊急度が高く支払い能力がある男性（と、その人へ贈るパートナー）に、
> 「第一印象を、プロチームと1日で、誰にも知られず変える」を売る。
> 薄利多売はしない。月間枠を絞り、専属・守秘・ワンストップで単価を正当化する。
> 最終更新: 2026-07-06

## 1. 誰に売るか — 「緊急×支払力」の4ペルソナ

高単価が成立するのは「**締切があり、失敗コストが高く、自分の時間が最も高い**」人。

| # | ペルソナ | 緊急の理由 | 支払力の根拠 | 入口メッセージ |
|---|---|---|---|---|
| P1 | **婚活を本気で決めたい男性**（30〜40代、結婚相談所・ハイクラスアプリ） | お見合い写真・プロフィールが今週必要。婚活の機会損失は月単位で痛い | 相談所に年30〜60万円払っている層 | 「その写真で、決まらないなら。」 |
| P2 | **経営者・役員・士業**（登壇・メディア・上場・重要商談・政治資金パーティー） | 人前に出る日が決まっている | 自分の見た目=事業の信用と知っている | 「大事な日は、プロチームで臨む。」 |
| P3 | **人生の再出発**（離婚後・大病後・昇進栄転・転職エグゼクティブ面接） | 「変わらなきゃいけない日」が来てしまった | 退職金・役職給・切実さ | 「もう一度、はじめから整える。」 |
| P4 | **贈り手**（妻・パートナー→P1〜P3の男性へ） | 記念日・昇進・結婚式が締切 | 世帯で支払う。夫に言えない分をお金で解決 | 「言えなかった応援を、贈り物に。」 |

**共通する購買心理**: 安さではなく「**外さないこと・手間がないこと・知られないこと**」に払う。
→ 訴求は割安比較ではなく、**専属チーム・ワンストップ・完全守秘・締切対応**の4点に統一。

## 2. 何をいくらで売るか — 商品・価格設計

### 2-1. 商品ラダー（3段）

```
① 印象診断セッション（入口・有料）
   90分 / 目安 ¥22,000
   印象カウンセリング＋改善ロードマップ提示。
   当日パッケージ申込みで全額をパッケージ代金に充当（実質無料化）。
   → 「無料相談」をやらないことで、冷やかしを切り、高単価の格を守る。

② 第一印象改善パッケージ（主力・フラッグシップ）
   1日完結 / 目安 ¥150,000〜（ヒアリング後に確定見積り）
   印象カウンセリング＋完全初心者向けメイク（施術＋再現レッスン）
   ＋服選び（プロ同行）＋写真撮影（ビフォーアフター）
   専属チーム（メイク・スタイリスト・カメラマン）を1日貸切・完全匿名。
   ＋ 緊急対応枠: 7日以内の実施は +30%（締切需要は価格が効かない）

③ ギフト券（贈り手向け）
   ¥165,000（②相当・有効期限6ヶ月・手紙同封）
   受け取った本人が匿名で日程と内容を決める（贈り手に内容は開示しない）。
```

### 2-2. なぜ ¥150,000 で売れるのか（価格の正当化）
- 単品市場の実勢（スタイリング3〜8万＋メイクレッスン1〜3万＋撮影1〜2万）を**足すと5〜13万**。
  当社は「束ねる」のではなく**専属チームで1日を設計する**ので、単純合算の上に
  「編成・進行・守秘・締切保証」の価値が乗る。**比較で安く見せるのではなく、比較の外に出る**。
- P1〜P3にとって代替案は「自分で3業者を調べ、3回説明し、3回予約する」＝時間コストが最大の敵。
- 月間枠を絞る（後述）ことで「予約が取れる高級店」ではなく「**枠が空いていたら幸運な専属サービス**」の位置へ。
- 価格は「目安〜」表示＋ヒアリング後の個別見積り。値引きは一切しない（優待は紹介・充当のみ）。

### 2-3. 売らないもの
- 廉価版・お試し無料・都度割引。②を分解した単品売り（撮影だけ等）もしない。
  ※ 例外: ①診断セッションのみ単体で成立させる（入口 兼 収益化された営業）。

## 3. どう立ち上げるか — フェーズ別実行計画

### Phase 0: 商品と器を固める（〜2週間）
**ゴール: 「今日申し込まれても受けられる」状態。**

| # | やること | 詳細 |
|---|---|---|
| 0-1 | **本番デプロイ確定** | 全ての前提。Vercel Secret 登録 or 手動 Redeploy |
| 0-2 | **価格改定をサイトへ反映** | 目安 ¥30,000〜 → ①¥22,000 / ②目安¥150,000〜 / ③¥165,000 の3段に |
| 0-3 | **提供体制の確定** | メイク・スタイリスト・カメラマンの業務委託先を各1名確保（守秘義務契約込み） |
| 0-4 | **契約・法務の器** | 利用規約（キャンセル規定含む）・NDA書式・業務委託NDA。決済導入時は特商法表記 |

| 0-7 | **実写素材** | 4ステップの実写（モデルは提供チームでよい）。高単価はビジュアルの質=価格の証明 |

### Phase 1: 有料で検証する（〜2ヶ月）
**ゴール: ファウンダー枠 5〜10件を高単価帯で売り切り、提供品質と「匿名の声」を確立。**

- **ファウンダー枠**: 先着5名、②を ¥110,000（定価の約7割・「創業枠」名目で、値引きでなく理由のある価格）。
  条件: 終了後の匿名アンケート＋匿名の声（文章）提供に同意。顔・実名は一切出さない。
- **どこで売るか（Phase 1 は手売り）**:
  - 自分・チームの一次ネットワーク（経営者仲間・士業・知人の紹介）に**個別に**案内
  - 結婚相談所の仲人 2〜3 人に「会員さん向けに1枠」持ち込み（P1の卸元。§4）
  - Threads/X では「創業枠・残り◯名」のみ告知（安売り訴求はしない）
- **検証すること**: ①→②の充当転換率 / 当日満足（NPS的な匿名アンケート）/ 原価と粗利 / 所要時間の実際
- **関門**: 5件成約＋「もう一度同じ品質で提供できる」運行表 → Phase 2 へ

### Phase 2: 販路を太くする（2〜4ヶ月）
**ゴール: 紹介・提携・ギフトの3販路から月3件以上。**

| 販路 | アクション |
|---|---|
| **結婚相談所・仲人提携**（P1） | 「成婚を早める外部サービス」として相談所に提案。会員は写真・印象で成婚率が変わることを仲人が一番知っている。※サイトにはB2B掲載しない（営業は水面下・紹介料は払わない=中立維持。相互紹介 or 会員優待枠で設計） |
| **紹介制度**（P2・P3） | 体験者からの紹介1件で次回①無料 or ギフト券1万円分。守秘と両立する「紹介カード」方式（SNS投稿は求めない） |
| **ギフトLP公開**（P4） | ③ギフト券の販売ページ＋贈る人向けの言葉（`MARKETING_GIFT_PARTNER.md` の実装）。記念日・昇進・結婚式前の3オケージョン |
| **オケージョンSEO/GEO** | 「お見合い写真 男 服装」「経営者 プロフィール写真」「離婚後 立ち直り 男」等のクラスタを /areas に追加 |

### Phase 3: 仕組みで増やす（4ヶ月〜）
- SEO/GEO の刈り取り本格化（`MARKETING_SEO_GEO.md` の面拡大を継続）
- 成約単価・CVRが見えた段階で小予算広告（「お見合い写真 メンズ」等の高意図×低CPCに限定）
- ハイエンド復活の検討: 年間伴走（アーカイブ済みの highend）を、②の体験者だけに招待制で案内（LTV の柱）
- 月間枠を 4→6→8 と計画的に開放（品質が崩れる拡張はしない）

## 4. 販売の型 — 高単価を守る5つの運用ルール

1. **月間枠を公表する**（例:「今月の受付 残り2枠」）。希少性は事実ベースで。
2. **値引きしない**。動かすのは「枠」と「特典（充当・紹介優待）」だけ。
3. **最終価格はヒアリング後**。見積り提示までを①診断セッションの中で完結させる（見積り=営業をお金に変える）。
4. **断る基準を持つ**。医療が必要なケース・期待値が合わないケースは①の段階で丁寧にお断り（守秘のまま）。高単価の信頼は「誰でも受けない」ことから生まれる。
5. **成果は約束しない**。約束するのは「専属チーム・1日・守秘・締切までの実施」というプロセス（薬機法/景表法の防衛線でもある）。

## 6. リスクと制約（変えない前提）

- **中立の維持**: 相談所・提携先から紹介料を受け取らない/払わない。優待・相互紹介で設計（「売らない・中立」がブランドの核のため）。
- **法務**: 効果断定・誇大禁止。決済導入時に特商法表記。医療行為はしない。匿名の声は本人同意＋個人特定不能の形式のみ。
- **守秘とマーケの両立**: ビフォーアフター写真の公開は原則しない（本人同意があっても慎重に）。売り物は「変化の物語」ではなく「体制と体験」。
- **B2C のみをサイトに掲載**: 仲人提携などB2B動線はサイト外で運用。
