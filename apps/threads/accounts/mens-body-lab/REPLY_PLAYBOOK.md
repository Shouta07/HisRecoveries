# 恋亀の返信

**この設計でいちばん効く手で、いちばん自動化できない場所**（`GROWTH.md` §6・§11）。

投稿は自動で出る。人がやるのは返信だけ。1日20〜30件・60〜90分。
これが表示数を動かす最大の変数で、投稿を1本増やすより効く。

> Threads API では、相手を探す側に壁がある（`threads_search` は
> `threads_keyword_search` 権限が要り、Meta のアプリレビューが未承認）。
> 技術的に通っても自動化はしない。面識のない人に機械が返信を配るのは
> 規約の線が別で、「実在の人が読む」を売っているのに、いちばん人格が
> 出る場所で機械が返すことになる。

---

## 0. 15分 × 2回

| | いつ | 何を |
|---|---|---|
| **直後の15分** | 自分の投稿が出た直後 | 来た返信に全部返す。**初速が露出を決める** |
| **夜の60分** | 21:00以降 | 他人の投稿に20〜30件返す |

自分の投稿への返信は**全部返す**。1件も落とさない。
投稿直後の1時間の反応で、おすすめに出るかが決まる（`READ_DESIGN.md` §0）。

---

## 1. どこに返すか

検索する言葉（Threadsの検索窓）:

```
マッチングアプリ   マチアプ   アプリ 疲れた
既読   返信こない   未読無視
デート 誘い方   2回目   初デート
脈   社交辞令   温度感
```

**選ぶ基準は3つ。**

| 返す | 返さない |
|---|---|
| 返信が0〜5件（埋もれない） | 返信が50件超（読まれない） |
| 迷っている・決めきれていない | 怒っている・傷ついている |
| 具体的な場面が書いてある | 一般論・格言・宣伝 |

**投稿から数時間以内のものに返す。** 1週間前の投稿に返すと、
巡回しているのが見える。

## 2. 恋亀の返信の型

### 型A 言い換える（いちばん多い）

相手が言ったことを、少しずらして返す。同意ではなく、言語化。

> 「既読ついてるのに返信こない。もう脈なしかな」

```
既読がつかん時間より、
ついてから返ってこん時間のほうが長いんよな。

恋亀もそれで1日溶かしたことある🐢
```

**「脈なし」に答えない。** 相手の気持ちの判定はしない。
しんどい**時間**のほうを拾う。

---

### 型B 見立てを出す

恋亀がどう読んだかを言う。外れていていい。

> 「2回目のデートで『また行こう』って言われたけど日程は決まってない」

```
恋亀にはちょっと前向きに見えた。
社交辞令なら「また今度」で止めるから。

でも日程が出てないのは事実やし、
そこは聞いてみてもええんちゃう🐢
```

**根拠を1行つける。** つけないと、ただの気休めになる。

---

### 型C 片側を聞く

男女差が出そうな話は、聞く。これがいちばん会話になる。

> 「初デートのあと、お礼のLINEって何時間後がいいんだろう」

```
これ、恋亀もずっと分からん。

受け取る側に聞きたいんやけど、
その日のうちと翌日の昼って、印象ちがう？🐢
```

**代弁しない。** 「女性はこう思う」は書かない。

---

### 型D 具体を1つ聞く

話が抽象的なとき。これだけで続きが始まる。

> 「マチアプ疲れた」

```
疲れるのは、会う前と会ったあと、どっちのほう？🐢
```

**短くていい。** 長い返信は読まれない。

---

## 3. 書かないこと

投稿と同じ線（`src/lib/koi/prompt.ts` の `NEVER`）。返信のほうが**事故りやすい**。
相手がいて、こちらが後から来ているので。

- **宣伝しない。** 「タシカメ使ってください」「よかったらこちら」は書かない。
  プロフィールを見れば分かる状態にしておけば足りる
- **脈あり・脈なしを判定しない。** 聞かれても答えない
- **説教しない。** 「それはよくない」「〜すべき」
- **代弁しない。** 「女性は」「男性は」と言い切る
- **診断しない。** 「それは不安型愛着かも」
- **傷の深い話に入らない。** 既婚者・ストーカー・金銭・暴力。
  **黙って離れる。** 中途半端に返すほうが悪い
- **連投しない。** 1つの投稿に1返信。食い下がらない
- **同じ文面を使い回さない。** 2人に同じ返信をした時点で、機械に見える

---

## 4. 返信が来たら

**全部返す。** ただし2往復まで。それ以上はDMでもなく、そっと終わる。

| 来たもの | 返し方 |
|---|---|
| 「わかる」 | 一言足す。「やんな。あれ何なんやろな🐢」 |
| 反論 | **歓迎する。** 「お、そっちか。理由きかせて🐢」 |
| 自分の話 | 具体を1つ聞く。相談に乗らない（それは有料の側） |
| 相談（長文） | 「それ、一人で決めるのしんどいやつやな🐢」で受ける。解かない |
| 絡み・煽り | 返さない。ブロックもしない。流す |

**反論が来たら勝たない。** 訂正されるために見立てを出している。
「そっちか」で受けるのが正解で、言い負かすと二度と書き込まれない。

---

## 5. やってはいけない近道

- **定型文を貼る。** 2人に同じ返信をした時点で終わり
- **フォローバック目当てに返す。** 数は増えるが、誰も読まない
- **1日に同じ人へ何度も返す。** 1人1日1回まで
- **自分の投稿のリンクを返信に貼る。** 一発で宣伝アカウントになる

---

## 6. 記録

返信そのものは測れない（Threads API に他人の投稿への返信の数値は無い）。
見るのは**翌日のアカウント全体**。

```
reports/weekly.md  →  フォロワーと表示数の増減
```

返信を増やした週に伸びていれば、効いている。
伸びていなければ、**返す相手の選び方**（§1）を変える。本数ではない。
