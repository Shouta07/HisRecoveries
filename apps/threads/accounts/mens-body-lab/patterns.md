# 連投パターン（タシカメ / 送る前に止まる瞬間）

タシカメ運営が、送信ボタンの前で手が止まる瞬間について書く。
流れ: 止まる瞬間 → なぜ決まらないか → 誰に聞けば分かるか → CTA(最終投稿に1つだけ) → 問い。

## 守ること

- **女性の反応を創作しない。** 「女性はこう思っている」と書かない。
  実在の回答が集まるまで、具体的な「女性の声」は投稿に出さない。
  それを売っているサービスが、AIの作り話を出したら商品そのものが嘘になる。
- **相手の気持ちを判定しない。** 脈あり・脈なしは扱わない。
- **効果を保証しない。** モテる・落とす・攻略は書かない。
- **読む人を責めない。** 手が止まるのは慎重さであって、欠点ではない。
- **AIや友達を否定しない。** 足りないところだけを書く。

絵文字0〜2、ハッシュタグ0〜1。CTAは最終投稿に1つだけ。

## 1. message
**場面**: 送る前のLINE
**構造**: 文面はできた → 読み返しても自分の目しか無い → 相手側の目を通す

## 2. photo
**場面**: 自己紹介文・プロフィール
**構造**: マッチはする、続かない → 書いた本人がいちばん読めない → 出す前に通す

## 3. date
**場面**: 誘うタイミング
**構造**: 早いと重い・遅いと冷める → 相手側にしか無い情報 → 材料を片側で決めない

## 4. signal
**場面**: デートのあと
**構造**: 楽しかった気はする → 相手からどう見えたかは別の話 → 次の一手の前に

## 5. distance
**場面**: 距離感・言いにくいこと
**構造**: 踏み込みたいが踏み込みすぎたくない → 友達にも相手にも聞けない → 同じ側の人に
