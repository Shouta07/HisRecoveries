# 最初の10本

アカウントは空から始まる（旧事業の153件は2026-10-03に削除済み）。
**最初の10本で、この亀が何者かが決まる。** ここだけは自動に任せない。

自動生成は型とテーマをランダムに掛けるので、最初の数本が
「告知→実演→告知」のように並ぶことがある。**誰もまだ恋亀を知らないのに、
商品の話が先に来る**状態になる。

だから最初の10本は手で決めて、`approvals.json` に積む。
11本目から自動に渡す。

## 1本目

いちばん大事。**自己紹介をしない。**

```
マチアプで一番しんどいの、

「嫌われた」
じゃなくて

「嫌われてるか分からない」

やと思う。
前者はまだ次に行けるからな🐢
```

**書かないもの**

```
はじめまして、恋亀です🐢
マチアプで出会ったあとの恋愛について喋っていきます。
よろしくお願いします。
```

誰もフォローしていないアカウントの自己紹介は、誰も読まない。
プロフィールに書いてあれば足りる。

## 10本目（最初の告知）

9本ぶん溜めてから出す。**止まる瞬間から入り、商品の説明から始めない。**

```
「このLINE、これでええんかな」

で10分止まったとき、
実在する女性に読んでもらえます。

どう受け取ったかと、その理由が返ってくる🐢

{link}
```

## 積み方

```
python -m core.main post mens-body-lab --mock --slot morning
python -m core.main queue mens-body-lab          # id を確認
```

文面を手で直すなら `approvals.json` の `payload.text` を書き換える。
**告知（D）の `link` は消さない。** `utm_content` の追跡コードが入っていて、
これが無いと、どの投稿が効いたかを後から見られない。

積んだ順に出る（`post-approved` は古いほうから1本ずつ）。

---

## この10本のあいだにやること

**返信のほうが大事**（`REPLY_PLAYBOOK.md`）。

投稿が10本あっても、誰も見に来ない。見に来るきっかけは、
他人の投稿への返信でしかない。10本を出す3〜4日のあいだに、
**1日20〜30件**返す。

10本目の告知を出すころに、プロフィールを見た人が何人かいる状態を作る。
それが無いと、告知は誰にも届かない。
