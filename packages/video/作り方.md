# 動画の作り方 — Claude Code × Remotion × VOICEVOX（× Playwright）

Shorts を1本作る手順。**あなたのPCで** 実行する（本番サイトでは動かない）。
できあがった mp4 は Google Drive「HR動画（Shorts）」に置いて配信する。

前提: このリポジトリを clone 済み。`npm install` 済み。動画は `packages/video`（@hr/video）。

---

## 全体像
```
① Claude Code : 記事 → RoadmapData(台本JSON) と ナレーション台本 を生成
② Remotion    : 台本 → 縦動画(9:16)
③ VOICEVOX    : ナレーション台本 → 音声(wav)  ※任意
④ Playwright  : サムネイル(1280×720) を生成      ※任意
⑤ Drive       : 完成物を「01_制作中」へ → 確認 → 配信
```

---

## ① Claude Code に台本を作らせる
対象記事（例 `/areas/skin/mens-skincare-junban`）を指定して、こう頼む：

> `packages/video/PROMPT.md` に従って、この記事から RoadmapData を作って
> `packages/video/data/<slug>.ts` に保存して。ナレーション台本も
> `packages/video/narration/<slug>.txt` に作って。

- 生成物は `data/<slug>.ts`（映像の文言）と `narration/<slug>.txt`（読み上げ）。
- Claude が `Root.tsx` の登録と `src/lib/studio.ts` の VIDEO_REGISTRY 追記までやる。
- 文字数オーバー・禁止語は `lib/validate.ts` がバンドル時に警告（ブランド・薬機法ガード）。

## ② 映像をプレビュー / 書き出し（Remotion）
```bash
# その場で見る・微修正（ブラウザが開く）
npm run studio -w @hr/video

# mp4 に書き出す
npm run render:<slug> -w @hr/video      # 例) render:skincare
```
→ `packages/video/out/<slug>.mp4`（9:16・約18〜20秒）。

## ③ ナレーションを付ける（VOICEVOX・任意）
```bash
# 1) VOICEVOX を起動（エンジンが http://127.0.0.1:50021 で待受）
# 2) 台本 → 音声
npm run voice -w @hr/video <slug>        # 既定話者=13(青山龍星)
# 3) data/<slug>.ts に  audioSrc: "audio/<slug>.wav"  を1行足す
# 4) もう一度 render
npm run render:<slug> -w @hr/video
```

## ④ サムネイルを作る（Playwright・任意）
```bash
# thumbnails.json に <slug> の title/subtitle を足してから
npm run thumb -w @hr/video <slug>        # → out/thumb/<slug>.png
```

## ⑤ Drive に置いて配信
1. Drive「HR動画（Shorts）」の `_雛形` をコピー → `<track>_<area>_<slug>_v1` にリネーム。
2. `out/<slug>.mp4` / `out/thumb/<slug>.png` /（音声wav）/ caption.md を入れる。
3. `01_制作中` に置く → スマホで確認 → OKなら `02_配信OK` へ。
4. 各媒体（YouTube/IG/Threads/note/substack）へアップ → `03_配信済み` へ。
5. `src/lib/studio.ts` の該当動画に `stage` と `distributed`（配信日）を記入 → Studio に反映。

---

## よくあるつまずき
- **音がこの環境で作れない**: VOICEVOX はあなたのPCで起動が必要（クラウドには無い）。
- **render で Chrome エラー**: `--browser-executable` は package.json の render スクリプトに設定済み。
  別環境なら `npx remotion install` で Chromium/ffmpeg を取得。
- **文言がはみ出す**: `lib/validate.ts` の警告に従い data の文字数を詰める（目安は PROMPT.md）。
