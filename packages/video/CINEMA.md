# Cinema — ブランドフィルムの制作規範

`lib/cinema/*` と `data/films/*` で作る、**映像作品**としての動画。
記事量産テンプレ（`lib/RoadmapVideo.tsx`）や文字主体のリール（`lib/BrandReel.tsx`）とは
目的が違う。ここは「説明しない」側の系統。

---

## 1. 映像ディレクション

### 狙い

25〜40歳の男性が、スクロールの途中で **手を止めて、最後まで見てしまう** こと。
情報を伝えるのではなく、**自分の話だと感じさせる**。

そのために全編で守る規律：

| やる | やらない |
|---|---|
| 画を先に見せて、後から言葉を置く | 文字で説明を始める |
| 1カット＝1つの意味 | 1カットに複数の情報 |
| 人を映さずに語る（光・素材・痕跡） | Before/After、症例写真 |
| 黒を深く、光を1箇所に絞る | 全面を明るくする、色を足す |
| 30秒で9カット（平均3.3秒） | 素早いカット割り、ビート合わせ |
| フェードとゆっくりしたズームだけ | スライド、回転、パーティクル |

### カット表（Awareness30 / 30.0秒 / 9カット）

| # | 秒 | 画 | カメラ | 言葉 |
|---|---|---|---|---|
| 1 | 0.0–2.6 | 夜明けの窓辺、後ろ姿（引き） | 押し 1.02→1.10 | — |
| 2 | 2.6–5.0 | 同じ場所へ寄る | 押し 1.22→1.32 | もっといい男に／なりたい。 |
| 3 | 5.0–7.4 | 洗面台の壁、ブラインドの影 | 横流れ | 肌。 |
| 4 | 7.4–9.7 | 横顔と肩（寄り） | 引き 1.72→1.62 | 体。 |
| 5 | 9.7–12.0 | 畳まれたタオル | 押し 1.50→1.58 | 清潔感。 |
| 6 | 12.0–16.0 | 全身（引き） | 引き 1.18→1.02 | 変わりたいと思った瞬間から、 |
| 7 | 16.0–20.0 | 明るくなる空の側 | 引き 1.16→1.06 | 人生は**少しずつ**変わる。 |
| 8 | 20.0–24.4 | 光の当たる面だけ | 押し 1.08→1.16 | — |
| 9 | 24.4–30.0 | 黒 | — | His Recoveries／伴走する。／導線 |

**なぜこの順か**: 1〜2で「ひとりの時間」に引き込み、3〜5で悩みを *並べずに* 触れ、
6〜7で思想を言い、8で息を継ぎ、9で名前だけ残す。
Cut 8（無言のカット）を削ると、ブランド名が押し売りに見える。

### 文字の置き場所

中央に置かない。**三分割の下段・左**（`FRAME.lowerY = 0.735`）。
映像の主題（人物・光）は上2/3にあるので、そこを潰さない。
ブランドカード（Cut 9）だけは中央。カードは写真ではないため。

## 2. 必要素材一覧

### いま使っているもの（3点／リポジトリ内から流用）

| ファイル | 元 | 使用カット | 備考 |
|---|---|---|---|
| `public/media/reel/dawn-window.jpg` | `public/cityscape-dawn.png` | 1, 2, 7 | 夜明け・後ろ姿。冒頭と終盤で同じ場所に戻る |
| `public/media/reel/morning-counter.jpg` | `public/room-morning.png` | 3, 5, 8 | **左側にサードパーティ製品のラベルが写る**。`x` を 86 未満にしない |
| `public/media/reel/window-portrait.jpg` | `public/media/hero/portrait.png` | 4, 6 | 窓辺の男性 |

3点を**別の寄り**で使い回している。カメラの寄り引きが違えば別カットとして成立するが、
本番としては素材が足りない。下の一覧を撮る（または調達する）と、使い回しが消える。

### 撮るべき素材（優先順）

| 優先 | カット | 内容 | 要件 |
|---|---|---|---|
| ★★★ | 1 | 朝、鏡の前に立つ男性（後ろ姿・顔は映さない） | 自然光のみ。鏡は曇っていてよい |
| ★★★ | 4 | 首・肩・鎖骨（寄り） | 肌の質感が出る斜光。露出はアンダー気味 |
| ★★☆ | 3 | 洗面ボウルに落ちる水／濡れた手 | 高速シャッター不要。むしろ少し流れてよい |
| ★★☆ | 5 | 畳んだタオル・剃刀・器（静物） | ブランド名の映り込みゼロ。無地の器物 |
| ★★☆ | 6 | 窓辺に立つ全身（引き） | 部屋の余白を大きく。人物は画面の1/3以下 |
| ★☆☆ | 8 | 壁の光だけ（人物なし） | 時間経過で光が動くカットが理想 |

**撮影条件（全カット共通）**
自然光のみ・ノーストロボ。露出はアンダー0.7〜1.3段。背景はコンクリート／無地の壁。
被写体の衣服は黒・チャコール・生成りのみ。ロゴの写り込み厳禁。
納品は 3000px 以上の JPEG（縦位置優先。横位置は 9:16 の切り出し代を残す）。

### 音

`public/audio/ambient-30.mp3` は `scripts/ambient.mjs` が生成した**プレースホルダ**。
55Hz の持続音を重ねただけのもので、公開前に権利処理済みの楽曲へ差し替える。

差し替え: `public/audio/` に置いて `data/films/awareness-30.ts` の `audioSrc` を書き換える。
音量は `audioVolume`（0–1）。ボイスオーバーを載せる場合は 0.25 前後まで下げる。

## 3. コンポーネント設計

```
lib/cinema/
  theme.ts        トークン。色・書体・タイポスケール・時間・版面・グレード
  fonts.ts        Inter / Noto Sans JP をローカル読込（weight 300 が主役）
  film.ts         型と defineFilm()。秒指定のカット列 → フレーム尺表
  media.tsx       Plate / Grade / Grain / LightPlate / TextScrim
  type.tsx        Reveal / Anchored / Word / Statement / Label / Wordmark / Caption
  layouts.tsx     silent / word / statement / brand の4レイアウト + CutRenderer
  Film.tsx        フィルム本体（カットを並べ、繋ぎ、頭尻を暗転）
data/films/
  awareness-30.ts この1本ぶんのカット表
```

### 責務の分け方

- **theme.ts が唯一の意思決定の場所。** 色・尺・余白の数字はここにしか書かない。
  各コンポーネントは `TIME.dissolve` のように読むだけ。トーンを変えるならここ1枚。
- **film.ts はデータ構造だけ。** React に依存しない。秒 → フレーム変換と、
  カットを次へ食い込ませる（＝ディゾルブ）計算を持つ。
- **media / type は「動きを持つ部品」。** レイアウトから組み合わせて使う。
- **layouts.tsx が絵の決めごと。** ここを読めば「このブランドのカットはこう組む」が分かる。
- **data/films/*.ts は文言とフレーミングだけ。** 新作を作る人はここしか触らない。

### 100本量産するときの手順

```bash
cp data/films/awareness-30.ts data/films/<新作>.ts   # カット表を複製
# 1. cuts の seconds / media.src / move / layout を書き換える
# 2. Root.tsx に <Composition id="<新作>" ... /> を1行足す
# 3. npm run ambient -w @hr/video -- <秒数> <名前>     （音が要るなら）
# 4. npm run render:film -w @hr/video                 （スクリプトを1行複製）
```

コンポーネントは**書かない**。既存の4レイアウトの組み替えで足りるように設計してある。
足りなくなったら `film.ts` の `Layout` に種類を1つ足し、`layouts.tsx` に実装し、
`CutRenderer` の `switch` に1行加える（3箇所・追加のみ・既存には触らない）。

### カメラ（Ken Burns）の書き方

```ts
move: CAMERA.push(50, 50, 1.0, 1.09)          // ゆっくり寄る
move: CAMERA.pull(52, 40, 1.18, 1.02)         // ゆっくり引く
move: CAMERA.drift(90, 84, 52, 1.16)          // 横に流れる
move: CAMERA.pushDrift({scale, x, y}, {...})  // 任意
```

`x` / `y` は素材のどこを画面中央に置くか（％）。**写り込みを外すのもここで行う**
（例: `morning-counter.jpg` は `x` を 86 未満にすると他社製品が入る）。
`scale` は 1.0 が `object-fit: cover` ぴったり。3秒で +9% 以上動かすと広告臭が出る。

## 4. 制作条件の対応表

| 条件 | 実装 |
|---|---|
| 縦型 9:16 / 1080×1920 / 30秒 | `FRAME` + `defineFilm` の合計 900 フレーム |
| 映画広告のテンポ | 9カット・平均3.3秒、ディゾルブ26f（0.87秒） |
| 余白 | 左右 92px、文字は下段左、1カット1情報 |
| ゆっくりしたフェード | `Reveal`（34f で立ち上がり、移動は6px） |
| Ken Burns / 自然なズーム | `Plate` の `useCamera`（ease はほぼ等速） |
| 文字は1文ずつ | `Statement` が行ごとに26f ずらして出す |
| 黒・チャコール・自然光 | `COLOR.black #0F0F0F` / `charcoal` / `Grade` の暖色ハイライト |
| #F5F5F0 | `COLOR.bone`（純白を使わない） |
| 落ち着いたブラウン | `COLOR.brown #8A6F55`。罫線・ハンドル・強調語1つだけ |
| Inter / Noto Sans JP | `fonts.ts`（`public/fonts` からオフライン読込） |
| 静かなアンビエント | `scripts/ambient.mjs`（差し替え前提） |
| 画像差し替え可能 | `data/films/*.ts` の `media.src` 1行 |
