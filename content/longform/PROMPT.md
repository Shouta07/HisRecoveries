# 記事 → note / substack 転用プロンプト

一次情報の /areas 記事1本を、note・substack 向けの「読み物（長文）」に転用するための
AI 指示書。動画（packages/video/PROMPT.md）と同じく、**源泉は記事。作り直さず、深める**。
出力は `content/longform/drafts/<slug>.md` にそのまま置ける Markdown。

## 役割（なぜ note/substack か）
- Refine（潜在層）を"育てる"面。検索では出会えない人に、読み物で信頼を積む。
- GEO にも効く（AIが引用しやすい、質問→要点の構造）。
- 動画（掴み）→ note/substack（深い理解）→ 相談、の中間を担う。

## 入力
- 対象記事: `/areas/<areaId>/<slug>`（src/lib/clusters.ts の該当エントリ）。
  lead / summary / sections / faqs / keywords を素材にする。

## 出力の型（Markdown）
```
# <タイトル（記事タイトルを読み物向けに少し柔らかく）>

<リード 2〜3文。悩みに寄り添い、この記事で何が分かるかを先出し>

## <質問形の見出し1>
<本文。記事の section を、具体例・理由づけで自然に膨らませる>

## <見出し2>
...

## まとめ
<3〜4行。要点を短く。次の一歩をそっと置く>

---
- もっと具体的に整理したい人へ: https://hisrecoveries.com/apply（無料相談）
- 元の要点記事: https://hisrecoveries.com/areas/<areaId>/<slug>

*（note タグ / substack subtitle 用メモ）tags: …*
```

## 分量・構造
- 1,200〜2,500字。見出し3〜5。1見出し＝1メッセージ。
- 冒頭で「結論・要点」を先出し（GEO・離脱対策）。
- 箇条書きは使いすぎない。読み物として文で運ぶ。

## トーン（ブランド絶対ルール）
- **断定・医療表現をしない**（治る/若返る/必ず/絶対/確実/ビフォーアフター）＝薬機法・景表法。
- **煽らない・責めない・見下さない**（ダサい/不潔/老けてる/情けない/男はみんな は禁止）。
- 静かな伴走の語り。「一気にやらない・1つずつ」「昨日の自分と比べる」の思想を通底させる。
- **記事にない新事実を作らない。** 記事の主張の範囲で、理由と具体で深めるだけ。
- 体験談・当事者の声は捏造しない（監修者の一般的視点までにとどめる）。

## 媒体差
- **note**: 末尾にタグ3〜5個（#メンズ美容 #自分磨き 等）。見出しは日本語で親しみ。
- **substack**: subtitle（1行の要約）を用意。ニュースレター体でやや語りかけ強め可。
- 本文は共通でよい。プラットフォーム差は末尾メモとsubtitleだけ。

## 手順
1. 対象記事の lead/summary/sections/faqs を読み込む。
2. 上の型で Markdown を生成（トーン厳守・新事実禁止）。
3. `content/longform/drafts/<slug>.md` に保存。
4. note / substack に貼って公開 → Studio に配信日を記録（将来）。
