# content/longform — note / substack 転用

一次情報の /areas 記事を、note・substack 向けの読み物（長文）に転用する置き場。

- `PROMPT.md` … 記事 → 長文の生成契約（型・分量・トーン・ブランド/薬機法ルール）。
- `drafts/<slug>.md` … 生成した下書き。note/substack にそのまま貼れる Markdown。

## 作り方（Claude Code に頼む）
> `content/longform/PROMPT.md` に従って、`/areas/<areaId>/<slug>` の記事を
> note/substack 向けの読み物にして `content/longform/drafts/<slug>.md` に保存して。

## 配信
1. 下書きを読んで整える。
2. note / substack に貼って公開（末尾のタグ・subtitle メモを使う）。
3. 動画と同じく Studio に配信状況を記録していく（将来、記事系の配信列を追加予定）。

現在の下書き: `otoko-jibunmigaki-hajimekata.md`（Refine・自分磨きの始め方）。
