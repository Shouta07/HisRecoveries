# 具体性プール

これは Shota（Nagi）個人の私的な記憶のリポジトリです。
公開サイトには絶対に出ません。Next.js は `internal/` を読みません。

## なぜ作るのか

His Recoveries の記事が「Nagi の声に聞こえる」ためには、
当事者にしか書けない**具体性のディテール**が必要です。

- どんな朝、どんな服、どんな道具、どんな匂い、どんな台詞、どんな視線。
- これらを抽象論ではなく**実体験のかけら**として持っていることが、
  AI が真似できない最後の砦になります。

このプールは、その「かけら」を 4 領域 × 100 項目、合計 **400 個**
書き出しておく場所です。

## どう使うのか

1. **書く時期**：このサイトを公開する前後の 3〜4 週間で書き切る。
   1 日 15〜20 項目 × 25 日のペースが目安。
2. **書く順番**：気にしない。
   今日思い出せたものから書く。順序は後で並べ替えられる。
3. **使うとき**：
   - 記事の角度を決めるとき、関連項目を 3〜5 個抜き出して下書きに混ぜる
   - AI 補助を導入する場合は、ここから抜粋してプロンプトに含める
   - Threads や X の単発投稿の素材としても使える

## 書くときの 4 つのルール

1. **真実だけ書く**。誰にも見せない前提なので、盛らない、削らない。
2. **抽象は禁止**。「辛かった」ではなく「電車のドアに肩を寄せて立っていた」。
3. **長さは 1〜3 文で十分**。エッセイ化はしない。素材集として書く。
4. **書いたら手を止めない**。書いている途中に評価しない。
   面白い／面白くないは、後で判断する。

## ファイル構成


## タグ規約（任意）

各項目に、関連タグを `#` 付きで添えると、後で検索しやすい：

- 時期: `#過去` `#現在` `#移行期`
- 場面: `#朝` `#夜` `#夏` `#冬` `#通勤` `#外食` `#デート`
- 道具/対象: `#服装` `#鏡` `#写真` `#薬` `#医療` `#家族` `#友人`
- 性質: `#感情` `#台詞` `#風景` `#決断` `#気づき`

例：
```
12. 通勤バッグの中に、いつも替えのインナーが二枚入っていた。
    多い日は三枚。十月の終わりまで、ずっと。 #過去 #夏 #服装 #通勤
```

タグは強制ではない。書く速度を落とすなら省略していい。

## 進捗トラッキング（任意）

各領域ファイルの末尾に、進捗欄を置いてあります。
書いた数を数えて埋めると、ペースが見える。

## プライバシー

- このリポジトリが Private GitHub repo であることを前提に書く。
- もし Public 化する予定がある場合は、書く前に必ず確認すること。
- 個人を特定できる固有名詞（実名、医師名、医療機関名、勤務先、駅名）は
  プールにも書かない。`[病院]` `[A 医師]` のようなプレースホルダで残す。

## 完成したあとに

400 項目が揃ったら、おそらく以下のことに気づきます：

- 自分が書ける記事のテーマが、はっきりと見えてくる
- AI 補助が要るか、要らないかの判断材料が手元にある
- 今後の記事執筆が、ゼロから書くのではなく**素材を編む作業**になる

それが、このプールを作る本当の目的です。
